# 顶角按钮、重复音效与截断修正

## 用户反馈

- 顶角文字未居中；X 太小，需要红色粗体 X，返回符号稍大。
- 顶部三个按钮一次点击声音，其余按钮疑似两次。
- 设置数值行右侧 +5 被截断。
- `/caudio_probe start 12` 听感合适。这是当前 30 秒测试音的单人听感结果；保留原版与其他版本，尚未确认全部素材或正式默认响度。

## 本轮修正

- 业务 Button 移除 `PopupButton` 与原生导航按钮类，使用明确的自有视觉规则，避免同时触发原生自动音效和服务器 `menu.click`。
- 服务器仍通过现有 PlaySound 服务只向点击者发送一次原生点击声，个人音量 0% 不发送；重复声音的实际消除仍待听音。
- 返回内容放在居中的独立容器中，符号 34px，文字 24px；X 改为红色粗体字母 X，40px，并明确水平、垂直居中。
- 业务尺寸与文字规则使用直接类或后代选择器；不再依赖父子 `>` 选择器。没有根据截图声称已证实该选择器在宿主中不支持。
- 数值按钮固定 56×48、去除内边距和原生字体边距，数字值宽 96，四按钮加数值共 320，外层预留 340；数字容器明确从左向右排列，保留 20px 余量。
- 原命令、权限、投票规则、个人数据及试听音频素材保留。透明度仍沿用上轮的对照修改，尚未补充通过验收的结论。

## 验证与部署边界

相关测试及资源编译结果见本轮构建记录。实际修改为三个布局、一份样式和对应回归检查；游戏插件源码未改变，本轮部署只需匹配的两端 VPK。未提交、推送或发布。

本轮 63 项相关测试通过，13 个资源编译及 VPK 校验通过。经用户确认，服务器和本机 VPK 已备份更新，服务器正常重启，19 个插件加载正常；部署后的两端 VPK 哈希一致，插件文件、个人设置及本机 gameinfo 保留。居中、截断和单次音效尚未通过实机验收。

匹配玩家包：`release-build/ingamemenu-audio/alignment-sound-20260928/tester-kit-alignment-sound-deployed-20260928.zip`。用户本机已安装，不需要重复运行。

## 游戏内检查

1. 更新匹配资源并重开游戏，确认左上返回内容与右上红色粗体 X 居中，符号不再太小。
2. 设置行应完整显示 −5、−1、当前值、+1、+5；分别检查管理员和玩家入口。指令列表、分页、投票行和提示框不得截断。
3. 草人杯音量 100%：移到按钮后等待，再单击，区分悬浮声和点击声；顶栏、数值按钮、返回/X、指令行均应只响一次。
4. 草人杯音量 0% 重复检查，草人杯菜单不应产生声音；游戏原本的声音不受改变。
5. `/caudio_probe stop` 后再 `start 12`，保留用户已报告的听感结果。后续导入其他 OGG 时仍测量实际响度/峰值并试听，不把这一个测试音的结果直接推广至全部素材。
