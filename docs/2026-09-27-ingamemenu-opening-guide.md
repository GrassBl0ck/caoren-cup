# 草人杯菜单：打开与自定义按键

## 最简单的打开方式

连接草人杯服务器后，在聊天栏输入：

- 普通玩家菜单：`/crcmenu`
- 管理员菜单：`/crcmenu_admin`，要求 `@css/root`
- 投票界面：`/crcvote`
- 返回上一级：`/crcmenu_back`；根页面返回游戏
- 直接退出菜单：`/crcmenu_exit`

管理员也能打开玩家菜单。玩家入口仅介绍普通玩家能操作的内容，管理员入口负责管理操作；个人设置是经本次要求新增的共同入口。

## 自定义快捷键

1. 在 CS2 的“设置 → 游戏”中启用开发者控制台。
2. 打开控制台，输入以下命令。聊天栏不要粘贴 `bind` 命令。

```text
bind "F6" "css_crcmenu"
bind "F8" "css_crcmenu_back"
bind "F9" "css_crcmenu_exit"
```

管理员可以额外设置：

```text
bind "F7" "css_crcmenu_admin"
```

F6/F7 再按一次会关闭对应菜单。以上按键只是示例，原来有用途的键请换成空闲键；草人杯不会自动修改玩家键位。

暂不建议把 Esc 覆盖为 `css_crcmenu_back`：覆盖会改变 CS2 原有暂停菜单入口，目前尚未实现“没有草人杯菜单时仍打开原生暂停菜单”的自动回退。界面只保留“返回”；直接退出使用 `css_crcmenu_exit`。

## 个人设置

两个菜单都有个人设置页，使用同一份个人偏好：

- 背景透明度：使用 −5、−1、当前值、+1、+5，保存 1% 精度；0% 完全不透明，100% 完全透明，文字和按钮保持清晰。
- 草人杯音量：统一服务已接入投票、网页提醒、旧 `/ps`、草人杯追加痛叫及伤害声，0% 不发送这些播放请求；需游戏内验证实际音量。原生菜单按钮声音仍未接入，不能宣称全部草人杯声音已受控。
- 不提供不可用的背景模糊设置；鼠标跟随效果未通过技术关卡，保持灰色背景。

偏好由 Core 按 SteamID 保存到 `CaorenCupCore/data/player-preferences.json`。旧菜单数据先备份再导入，旧文件保留；任意冲突会停止整批导入。损坏数据进入只读保护；写盘失败会提示，已经更新的内存值仅在本次运行有效。

玩家菜单默认打开指令列表，顶栏可切换投票、个人设置和打开指引。从玩家菜单进入的投票页返回指令列表；直接 `/crcvote` 打开的独立页返回游戏。

## 如果没有显示界面

界面需要匹配版本的菜单资源。统一资源包构建工具输出 `caoren_resources.vpk`；当前仍未完成工坊发布与进服自动分发验收，快捷键不能代替资源安装。不要把新代码与旧资源包混用。

没有界面时，投票仍可以聊天输入 `/crcvote A`、`/crcvote B` 等完成。

## 恢复键位

在控制台输入 `bind "F6"` 可以查询这个键的当前绑定。修改前记下原绑定，退出测试后恢复它；不要用不加区分的解绑覆盖已有个人设置。
