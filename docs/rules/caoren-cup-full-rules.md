# 草人杯完整规则

更新日期：2026-08-01

## 一、草人杯简介

《草人杯》是由 GrassBl0ck（草方块）发起的 CS2 自定义玩法合集。它以熟人娱乐、竞技整活和插件规则为核心，通过服务器指令、插件配置和网页对局指挥台，把普通 CS2 对局扩展成多种规则模式。

本文档中的“我”一般指 GrassBl0ck / 草方块。玩家可以直接称呼为“草”。联系方式：QQ：3465434029。

草人杯的目标不是追求最严肃的电竞环境，而是在尽量公平、清楚和可控的前提下，让参与者在熟悉的 CS2 框架里玩到不同的对抗体验。

## 二、进入服务器与赛前准备

1. 在 CS2 设置中启用开发者控制台，默认按键为“~”。
2. 进入服务器前，建议在控制台输入 `snd_toolvolume 0.3`，用于降低服务器自定义音效的音量。该值范围为 0 到 1，0 表示关闭，1 表示最大，推荐 0.3 到 0.5。
3. 在控制台输入 `connect 119.45.166.182:27015` 连接服务器，也可以使用草人杯客户端中的“连接 CS2”按钮。
4. 若弹出创意工坊地图下载请求，请选择允许或下载。
5. 参与网页指挥台流程时，先登录玩家中心并明确点击“加入本场比赛”，再连接 CS2。

### 2.1 玩家中心账号登录

玩家统一使用草人杯账号和密码登录玩家中心。SteamID64 只作为由 CS2 插件确认的可信游戏身份，不再作为登录凭据。网页登录成功后不会自动参赛；需要明确点击“加入本场比赛”。

> 密码提醒：草人杯当前使用 HTTP。应使用只给草人杯使用的独立密码，不要与 Steam、QQ、邮箱、游戏平台或其他网站共用。

### 2.2 开户与账号恢复

没有账号，或忘记账号、密码时，在 CS2 服务器聊天栏输入 `!cclogin`。插件会根据服务器读取的可信 SteamID64 发放一次性游戏码；回到玩家中心输入该码即可开户或恢复账号。`!cclogin` 是唯一的开户与恢复入口。

## 三、玩法分类总览

| 玩法 | 简介 |
| --- | --- |
| 娱乐玩法 | 每回合随机或指定应用一种玩法修改，重点是整活与体验。 |
| 不平衡竞技 | 双方人数不等。人数较少方通常更强，必要时会获得技能点、buff 或其他补偿。 |
| 卧底模式 | 双方人数相等，并存在士兵、卧底、侦探三类身份。卧底通过隐藏身份、完成任务和影响本队胜负获得分数。 |
| 平衡竞技 / 无卧底竞技 | 使用网页指挥台完成选队长、选人、地图 BP 与选边，但不启用卧底、侦探和九宫格任务。 |
| 一人成军 | 极端不平衡竞技，一般为 1-2 人对抗多人。少人方称为独勇者，多人方称为挑战者。 |

## 四、网页对局指挥台通用流程

网页对局指挥台用于管理从大厅集结到最终结算的完整对局流程。它不仅服务于卧底模式，也可以用于不启用卧底的平衡竞技或其他需要“选人、选图、选边”的对局。

### 4.1 大厅与本场确认

使用账号密码登录玩家中心后，明确点击“加入本场比赛”。连接 CS2 后，桥接插件用服务器可信 SteamID64 核对本场身份。SteamID64 不用于登录，也不允许改绑其他账号。

管理员密码登录是独立管理流程，不会自动成为参赛玩家。

Lobby 以外阶段临时加入的玩家默认作为旁观者，不直接加入当前对局阵容。

### 4.2 队长、Roll 点与蛇形选人

1. 系统或管理员选出两名队长，记为 A 队队长与 B 队队长。
2. 两名队长进行 Roll 点，点数更高者获得流程优先权；如管理员另有指定，以管理员指定为准。
3. 选人采用蛇形顺序：一方先选 1 人，另一方连续选 2 人，此后双方按 2 人一组交替，直至所有参赛玩家被选完。
4. 每轮选人有倒计时。超时未选时，系统会从可选玩家中自动选择一名。

### 4.3 地图 BP

1. 地图 BP 采用卡片式投票。轮到某队 Ban 图时，该队所有在线队员都可以在倒计时内点击地图卡片投票。
2. 没有确认按钮，玩家可以在倒计时结束前反复改选。
3. 倒计时结束后，系统统计该队票数，Ban 掉票数最高的地图。若平票，则在平票地图中随机；若无人投票，则随机 Ban 一张可用地图。
4. 每轮默认 Ban 1 张地图，双方交替进行，直到只剩最后一张地图。
5. 地图卡片会显示本队玩家当前分别选择了哪张图，便于队内协调。

### 4.4 阵营选择

1. 地图确定后，指定队伍进入选边投票。
2. 该队所有在线队员都可以在 CT 与 T 两个选项之间投票。
3. 没有确认按钮，倒计时结束后选择票数更多的一方。平票或无人投票时随机。
4. 选边完成后，网页进入身份分配或赛前准备阶段。

### 4.5 赛中与赛后

- LiveGame 阶段由插件同步当前地图、比分、回合和已确认玩家的战绩数据。
- 任务类内容不强制与游戏事件同步，复杂任务由玩家或管理员在网页上手动确认。
- 比赛结束后可导入 MatchZy CSV，网页据此重新计算最终成绩。
- 管理员保留终止本局、手动修正比分、强制推进流程等应急权限。

## 五、通用行为规则

1. 禁止作弊。草人杯以熟人娱乐为主，开挂没有任何意义。
2. 避免红温。队友失误时，优先理解为“娱乐赛没有拉满认真程度”；如认为规则设计有问题，请及时反馈给管理员。
3. 保持圈子环境干净。邀请新玩家时，邀请人需要对其行为有基本判断，避免明显影响他人体验的人加入。
4. 游戏内语音用于必要沟通，例如暂停、规则疑问、卡住、整活说明等。禁止长时间吵闹、吼叫或恶意干扰他人操作。
5. 若需要紧急暂停，请直接在游戏内语音说明。管理员会尽量及时处理。
6. 部分插件修改无法立即在当前回合完全生效，必要时管理员可能通过快速结束当前回合的方式让修改在下一回合生效。

## 七、各玩法规则

### 7.1 娱乐玩法

娱乐玩法以每回合随机或指定规则修改为核心。若玩法标题前带有“<>”，其中内容表示该玩法的武器或道具限制；若没有该标记，默认所有武器与道具均可使用。

- 近战武器是否允许，原则上取决于它是否明显强于玩法主武器。若玩家除近战外没有任何输出方式，则近战一定允许。
- 部分限制由于技术原因难以硬性封禁，因此属于君子协定。
- 娱乐玩法可能包含大量音效和视觉效果，建议降低游戏音量。

### 7.2 不平衡竞技

不平衡竞技适用于双方人数不等的对局。人数较少的一方通常由纸面实力更强的玩家组成，并可能获得技能点、buff 或其他补偿，以弥合人数差距。

#### buff 类型示例

- 伤害：调整指定阵营受到或造成的枪械伤害倍率。
- 炸弹：调整 C4 引信时间。
- 道具：使指定阵营重生时获得指定投掷物。
- 武器：使指定阵营重生时携带或回合中获得指定武器。
- 经济：减少全场经济，或给予人数较少方额外经济。
- 时间：调整回合时间、冻结时间或其他计时参数。
- 治疗针：提供抗性针、恢复针、无敌针、治疗针、附魔金苹果针、强效针等效果。
- 透视、二段跳、血量、移速、隐身、复活、枪械数据、定身等其他修改。

#### 技能点流程

1. 首先确定人数较少方。优先尊重玩家意愿，人数仍不足时，由实力较强者优先进入少人方。
2. 人数较多方先禁用地图，人数较少方从剩余地图中选择，随后由人数较多方选择攻守阵营。
3. 人数较少方开局获得若干技能点。
4. 比赛开始前可花费 2 / 5 / 9 点购买一个至少贯穿半场的随机修改。
5. 对局中可通过 `.sp 1/3/5/r` 申请消耗技能点。服务器会在下一个冻结时间暂停，并从对应技能池中抽取修改。
6. 随机技能会消耗 0 到 5 点技能点，技能强度与消耗点数不完全对应。
7. 半场时，若比分不相等，则给落后方额外技能点：4 + 2 × 落后分差。

| 技能点档位 | 示例效果 |
| --- | --- |
| 1 点 | 获得 20% 子弹免伤；C4 引信缩短 5 秒；所有玩家获得抗性针。 |
| 3 点 | 获得 40% 子弹免伤；C4 引信缩短 10 秒；所有玩家获得无敌针。 |
| 5 点 | 获得 60% 子弹免伤；C4 引信缩短 18 秒；允许复活队友。 |

- 若随机结果为“给予武器”，玩家可以提出想要的武器类型；第一回合和第十三回合仅限手枪。
- 玩家可以选择放弃修改并退还全部技能点。
- 部分技能可指定触发条件，例如“我方仅剩一人时复活”。若管理员没有询问，则按默认触发方式。
- 因插件故障导致修改完全未生效时，返还全部技能点；部分生效时酌情返还。
- 每回合单边最多消耗 5 点技能点；开局贯穿半场的修改不计入此限制。
- 随机技能与固定点数技能通常不兼容。

### 7.3 平衡竞技 / 无卧底竞技

平衡竞技是最接近原生 4v4 或 5v5 的模式。它可以使用网页指挥台完成选队长、Roll 点、蛇形选人、地图 BP 和选边，但不启用卧底、侦探、九宫格任务和指认结算。

1. 进入网页大厅并完成本场确认。
2. 选出两名队长，进行 Roll 点。
3. 通过蛇形选人组成 A / B 两个阵容。
4. 使用官匹式地图 BP 投票确定地图。
5. 通过队内投票确定 CT / T 初始阵营。
6. 进入正常竞技对局。最终胜负按 CS2 / MatchZy 比分判定。

### 7.4 一人成军

一人成军是极端不平衡竞技，一般为 1-2 人对抗 N 人（N≥5）。少人方称为独勇者，多人方称为挑战者。服务器会给独勇者非常有利的修改，或给挑战者施加限制，以弥合巨大人数差。

1. 首先决定谁成为独勇者，谁成为挑战者。
2. 挑战者禁用一张地图，独勇者从剩余地图中选择本局地图，随后挑战者选边。
3. 其余流程按不平衡竞技处理。
4. 独勇者默认护甲不会损坏。

## 八、卧底模式详细规则与计分

### 8.1 模式简介

卧底模式是草人杯的核心身份玩法。双方人数相等，通过网页指挥台完成分队、选图和选边。正式开始前，双方会分配士兵、卧底、侦探等身份。

- 士兵：目标与正常竞技基本一致，尽量帮助本阵营获胜，并在终局正确指认卧底。
- 卧底：在尽量不暴露身份的前提下，完成任务并影响本阵营表现。
- 侦探：在中场问答和终局指认中判断双方卧底身份。通常在总人数较多时启用。

### 8.2 卧底模式流程

1. 所有参赛玩家进入网页大厅并完成本场确认。
2. 系统选出两名队长，进行 Roll 点和蛇形选人。
3. 双方交替进行官匹式地图 BP，每轮 Ban 1 张图，直到剩余最终地图。
4. 指定队伍进行 CT / T 选边投票。
5. 管理员在网页上分配卧底、侦探和士兵身份。身份通过网页私密显示或管理员私聊告知。
6. 每名卧底获得 3×3 九宫格任务。卧底可在正式开始前熟悉任务内容。
7. 所有玩家准备完毕后进入正式对局。
8. 第 12 回合结束后进入中场问答。侦探可提出关于卧底任务的问题。
9. 对局结束后导入或同步战绩，进入终局指认。
10. 网页根据战绩、任务、指认与胜负计算最终分数。

### 8.3 卧底任务规则

- 卧底任务以 3×3 九宫格形式展示，共 9 个任务。
- 在无特殊说明时，任务只需在限定范围内完成一次即可标记完成。
- 完成任务可获得任务等级 × 5 分。
- 三个已完成任务连成横、竖或斜线时，每条线额外 +14 分。同一条线只能计分一次。
- 支持 N 的任务可以累计或单回合多次完成，具体以任务描述和任务类型为准。
- “5/4N”类任务表示 N=1 时按 5 级计分，后续每增加 1 个 N 额外按 4 级叠加。
- 任务完成后，不应再使用放弃、提示、替换等操作；如需修正，由管理员处理。

| 标记 | 说明 |
| --- | --- |
| 普通等级 1-6 | 数字越高，通常难度越大。6 级极其稀有。 |
| 3N / 4N 等 | 按 N 值累计或单回合达成，分值与任务等级相关。 |
| 5/4N | 第一次按 5 级，后续每次按 4 级叠加。 |
| 备用任务 | 用于替换指定任务的隐藏任务，替换后不可撤销。 |

### 8.4 侦探问答

1. 第 12 回合结束后进入中场问答。
2. 侦探有 45 秒时间向管理员提出两个问题，问题应围绕卧底任务或卧底行为。
3. 若第一个问题答案为“是”或“部分是”，则不再回答第二个问题。
4. 若问题与任务明显无关，管理员可以拒绝回答并直接进入下一个问题。
5. 侦探只需猜测任务目标本身，不必精确到所有限定条件或具体次数。
6. 若管理员回答了第二个问题，该侦探最终计分时 -12 分。

### 8.5 终局指认

- 对局结束并完成数据统计后，进入指认环节。
- 每名玩家拥有一次指认己方卧底和一次指认敌方卧底的机会。
- 玩家不得放弃指认。
- 士兵指认己方卧底计 2 票，指认敌方卧底计 1 票。
- 侦探票数翻倍，指认己方卧底计 4 票，指认敌方卧底计 2 票。
- 卧底被指认的有效票数会影响其扣分；若被指认票数达到 2 × 单边人数，则额外扣 50 分。

| 伤害 | 每造成 100 点伤害 +0.9 |
| 问答惩罚 | 管理员回答第二个问题后 -12 |

侦探指认己方卧底计 4 票，指认敌方卧底计 2 票。因此侦探若两个方向都指认正确，最高可通过指认获得 6 票 × 20 = 120 分。

### 8.7 卧底模式额外规则

1. 禁止以“指认卧底”为名进行明显刻意、缺乏合理理由的队友击杀。
2. 卧底应尽量隐藏身份，但可以在合理范围内使用误导、离间等策略。
3. 在残局或需要大量有效交流的场景中，任何玩家都不得通过噪音、吼叫等方式严重干扰其他玩家操作。
4. 同一名玩家不能同时担任侦探与卧底。
5. 同一名玩家原则上不能连续两局担任队长，除非管理员因人数或流程需要另行决定。
6. 若局势失控或规则出现严重漏洞，可以私聊管理员请求暂停或终止本局。

## 十一、常见问题

### Q1：在内战中怎么分辨谁更强？

主要靠自觉判断。参与者多为熟人，大家对彼此水平通常有一定了解；若刚认识，建议坦诚交流，随着场数增加自然会更准确。

### Q2：草人杯一般在什么条件下开？

最低建议除管理员外 ≥7 人（总人数 ≥8），可进行 3v5 不平衡竞技、4v4 或 4v4 卧底模式；理想状态是除管理员外 10 人左右。服务器最大承载人数为 16。

### Q3：ping 很高或很卡怎么办？

服务器位于江苏。距离较远的玩家可能出现高延迟或丢包，可尝试使用加速器并选择华中或临近节点。

### Q4：我也想开一套草人杯，需要准备什么？

至少需要一台电脑或云服务器作为游戏服主机、足够性能承载插件与脚本，并熟悉 cfg 与插件配置。可联系 GrassBl0ck 咨询。

### Q5：为什么对局中有时会暂停？

部分玩法和插件需要管理员现场观察、修正或执行指令。若等待无聊，可输入 `!snake` 玩一会儿贪吃蛇。
