# 草人杯 CS 消息发送清单（2026-11-06）

状态：2026-11-07 已部署并通过加载、文件校验和无真人控制台命令检查；真人聊天视角仍待验收。用户已授权部署后提交、合并 main 并推送。

## 共同规则

- 每条主动发送的聊天和控制台回复带恰好一个 `[草人杯]`。
- 单人回执、查询、帮助、个人偏好和私密信息：绿色。队伍或指定小组共同通知：黄色。全服共同消息：红色。
- 涉及其他玩家、队伍或全服规则的管理修改，公开目标、实际内容及生效时机，不公开操作者姓名、账号或来源。开启、修改、关闭、清除、恢复默认使用同一原则。
- 失败不报成功；批量和异步动作明确“已请求”“部分成功”“下回合生效”。自动逐帧更新、HUD 刷新、重生重施不刷公示。
- 工具统一分行并按每条 240 UTF-8 字节拆分，中文和 emoji 不从字符中间截断。控制台去掉游戏颜色控制码。

## 工具兼容与发布注意

主要插件继续使用 CaorenCupContracts 中的统一工具。俄罗斯方块和换肤仍为 net8.0，编译链接同一份 CaorenCupChat.cs 源码，不改为 net10.0，也不引入新 DLL 或 NuGet 包。

本次修改了共享 Contracts 以及多个调用方；后续部署须按交付清单配套更新共享 Contracts 与受影响 DLL，不能只替换 FunCommands。2026-11-07 已按授权配套部署；没有创建正式 Release。换肤主 DLL 配套更新其 MySqlConnector 2.6.1，配置、数据与音频清单保留。
