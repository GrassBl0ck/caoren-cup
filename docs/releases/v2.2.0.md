# Caoren Cup 2.2.0：头部缩放、即时制坐垫战争与跨时代原型

本版纳入 2.1.0 后完成的 CS2 头部玩法、MC 坐垫战争 B、跨时代战斗管理与 MC 目录整理。三个主包分别提供 CS 服务器插件、共用网页端和 MC 内容；实验模块的收录不代表真人验收完成。

## 一、网页端

### 1. 故障修复

本次没有新增网页业务修复，保留共用账户设置与 CS / MC 门户。

### 2. 新增/修改内容

网页包发行版本更新为 2.2.0；不改变账号、会话、邮箱验证或玩家数据结构。

## 二、游戏插件

### 1. 故障修复

- CS2 头部缩放接入原生玩法开关及玩家处理时序，解决命令成功但外观不变、射击时倍率被恢复为 1 的问题。
- 避免服务端冷启动过早探测字段导致网络元数据被错误缓存；关闭模块时恢复头部倍率及原生开关的原值。
- MC 坐垫战争 B 补齐地图边界、AP/库存补偿、玩家恢复、投射物结算、观战限制及命令初始化/补全的本地回归验证。

### 2. 新增/修改内容

- **CS2 `/hd`，归入 CaorenCupFunCommands：** `/hd 0` 关闭；`/hd 1 [强度]` 按本场击杀减死亡进行非线性缩放，默认强度 1，0 净击杀为 1x，两端趋近 0x 与 3x；`/hd 2 <名字片段|t|ct> <倍率>` 手动设置，范围为 0＜倍率≤20。
- 自动与手动模式互斥，切换清空旧规则；个人设置优先于队伍。加入、换边、重生、同地图重连按既定规则处理；换图、重载及 `/reset_plu` 关闭清空。帮助与大倍率提示已接入。
- **MC 坐垫战争即时制 B：** 独立 CushionWarsRealtime 插件，主命令 `/cwb`，支持 1v1～8v8 同步行动、个人 AP、90 秒截止、缩圈、地图模板编辑与权限过滤的补全。当前为本地候验版本，真实服务端与多人试玩待验收。
- **MC 跨时代阶段04：** CrossEraCombat 0.1.0-dev 提供 old/modern 规则管理与观察日志，通过 OCM v2.8.0 公开 API 工作；默认不启用，不包含自研伤害重算。管理/配置检查已完成，真实战斗及原版对照仍待验收。
- MC 坐垫战争 A、B 与共用资料归入统一总目录，更新实际构建/校验/CI 路径；保留原导入路径、哈希和许可的历史来源记录。

## 五、安装与兼容说明

- 提供 `CaorenCupServer-服务器插件合集-v2.2.0.zip`、`CaorenCupWeb-网页端-v2.2.0.zip`、`CaorenCupMC-服务器内容-v2.2.0.zip`。各包附安装说明和逐文件 SHA-256 清单，按实际变化选择升级，不能整包覆盖生产配置或玩家数据。
- **大头已知限制：** 约 3x 的实测效果符合预期；超过 3x 时，部分可见头部边缘仍可能无法命中。手动范围保留到 20x，命令与帮助会提示限制，不宣称 20x 全边缘与外观完全一致。
- **大头原生适配：** 当前只支持已核对的 Linux CS2 1.41.9.4 服务端二进制。原生入口有版本校验；游戏更新改变二进制后会拒绝启用，需要重新核对适配。语音音调与完整延迟/遮挡组合未独立验收。
- CS 运行环境沿用项目声明的 MetaMod / CounterStrikeSharp 依赖，不随包替换框架。音频清单沿用已核对的既有资源，工坊与 RUSH 补丁按安装文档单独准备。
- MC 需要 Java 25 与兼容 Paper API 26.3 的服务端。包内坐垫战争 A/B 现已分目录；B 仅在显式选择 `cushion-wars-b` 并提供有效配置后启用，A/B 不同时启用。
- 跨时代管理插件需要另行准备 OCM v2.8.0；本包保留 OCM 完整参考源码和 MPL-2.0 许可，不分发其组合 JAR。实验配置示例不自动安装或覆盖现有配置，外层保持单实例、只启用当前地图插件。
