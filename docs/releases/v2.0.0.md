# Caoren Cup 2.0.0：CS / MC 双板块与统一账户

草人杯首页增加板块选择：登录一个草人杯账户，即可进入 CS 大厅或 MC 玩法与入服页面，并随时切换。仓库按 `cs/`、`mc/` 分别管理源码，网站和账户继续共用。

## 一、网页端

### 1. 故障修复

- 网站账户可以独立于游戏注册和登录；参加 CS 前另行验证游戏身份。
- 兼容原有账号、身份及数据关联，补绑邮箱不创建新身份或合并其他账号。
- 保持桌面壳的设备登录、会话恢复与退出流程，切换板块不自动加入或退出比赛。

### 2. 新增/修改内容

- 邮箱验证码注册，自设账号密码；支持老账号补绑邮箱和邮箱找回密码。
- 已绑邮箱的账号通过邮件恢复；未绑邮箱的老号保留一次性游戏码恢复入口。
- 登录后选择 CS / MC。CS 保留原大厅，MC 展示介绍、玩法、版本和正版 Java 入服指引。
- 邮箱验证码按邮箱、用途及绑定账号校验，限制重发、猜测及重复使用。
- Steam 快捷登录继续关闭；源码中的历史模块不作为网站登录入口。

## 二、游戏插件

### 1. 故障修复

本轮未修改既有 CS 玩法规则。

换肤组件的 MySqlConnector 升级为 2.6.1，修复上游公布的 TLS 认证安全问题，见 [GHSA-473q-m89c-ghf8](https://github.com/advisories/GHSA-473q-m89c-ghf8)。该修复包含在服务器发行包中，安装时按对应组件清单更新。

### 2. 新增/修改内容

既有 CS 插件源码归入 `cs/`，DLL 名称、安装分类和配置数据归属保持原状。完整服务器包按原有组件清单构建，取得整包后仍应按实际变更选择安装。

MC 自研插件、地图数据包与构建工具归入 `mc/`。坐垫战争保持试玩待验收状态，跨时代 PvP 保持实验与观察原型状态。

## 三、桥接插件

### 1. 故障修复

统一私聊提示接入既有消息工具，保留草人杯前缀和对应颜色。

### 2. 新增/修改内容

- `/ccreg` 提供网页邮箱注册指引，不再要求玩家在游戏聊天中输入密码。
- `/cclogin` 生成一次性码，登录网站后绑定服务器确认的 CS 身份。
- 拒绝自动转移已经属于其他账号的 Steam 身份；旧插件注册接口不能绕过邮箱验证开户。

## 四、小游戏插件

### 1. 故障修复

本轮没有修改既有 CS 小游戏玩法。

### 2. 新增/修改内容

CS 小游戏源码归入 `cs/mini-games-plugin/`。MC 小游戏数据包按固定来源收录，原作者署名和许可保留；大地图及音频按固定版本另行下载，避免混入普通源码历史。

## 五、安装与兼容说明

- 提供三个主包：CS 服务器插件合集、共用网页端、MC 服务器内容包。网页桥接 DLL 位于 CS 包；MC 包内按坐垫战争、小游戏合集和跨时代实验分别说明安装内容与成熟状态，不装入 CS 插件目录。
- MC 包包含自研插件 JAR、地图数据包、固定资源下载工具和全部收录源码。OCM 参考工程以完整源码及构建入口提供，实验内容不默认启用；大地图与音频继续按固定版本另行获取。
- 网站与本轮网页桥接应配套更新。保留原有账号、会话、比赛、偏好和数据库配置，示例配置不能直接覆盖生产配置。
- 邮件服务需配置专用发信邮箱的 SMTP 授权码；示例不含真实凭据。未配置时已有账号仍可登录，新邮箱注册不可用。
- 账户存储升级到 schema 4，兼容旧版读取。升级前独立备份完整运行数据；回滚旧程序时需要匹配的旧数据快照，并保留升级后的新增数据。
- 验证码目前保存在单进程内存中，重启后未用验证码失效；部署多个实例前需准备共享验证码与限流存储。
- Minecraft 仅允许通过正版验证的 Java 玩家进入服务器；草人杯网站账户与游戏正版验证分别进行。
- 自研 MC 使用 MIT；OldCombatMechanics 保留 MPL-2.0，小游戏合集保留 CC BY-NC-SA 4.0 及作者附加条款。各组件许可分别适用。
- 暂停与私有组件继续排除；框架、工坊资源和客户端按各自版本与安装说明处理，不因本次网站升级自动替换。

验证覆盖网站自动检查、CS 相关测试、MC 源码与资源校验、桌面/手机布局、真实邮件投递和网站上线检查。真人 CS 绑定及 MC 玩法体验由使用者在相应游戏客户端继续验收。
