# Caoren Cup v2.2.3

本次整合异能 BP 与自有比赛运行时、灵空战锋首版、跨时代 PvP 后续修复，并整理项目首页和 MC 发行内容。正在进行的翻译工作不纳入此版本。

## 一、网页端

### 1. 故障修复

- 对齐异能分支与当前 CS / MC 门户、模式选择、身份校验和会话恢复流程。
- 保留随机乱斗的完整 24 回合和无加时规则，避免被标准竞技的赛制覆盖。
- 修复自有运行时 MR3 加时被旧竞技 13 分规则提前判结束的问题；比赛结束以运行时权威阶段为准。
- 按回合身份与事件发生顺序记录个人统计，处理战斗遥测迟到、重复发送和恢复后的旧事件，补齐回合数、KAST、残局、多杀、生存时间与保枪统计。

### 2. 新增/修改内容

- 接入异能职业 Ban/Pick、职业分配与插件确认同步。职业配置未得到当前比赛的有效确认时，禁止正式开赛。
- 接入自有比赛运行时的准备、暂停、恢复和状态展示。使用独立、默认关闭的启用开关，升级旧会话不会自动接管比赛。
- 总 README 按项目介绍、CS、MC、部署与下载、致谢与仓库引用重新组织；详细操作链接到专题文档。

## 二、游戏插件

### 1. 故障修复

- 适配当前拆分插件、共享契约和模式生命周期，避免旧异能实现覆盖后续模式与娱乐功能。
- 清理坐垫战争探针中已失效的旧地图函数提示。

### 2. 新增/修改内容

- 整合异能职业同步、运行状态和正式比赛事件衔接。
- CS 娱乐、随机乱斗、RUSH、单挑和玩家工具使用配套 v2.2.3 组件；本次未重新设计其既有玩法规则。
- 保留既有性能计时调用；私有诊断主体和开发探针不随正式 CS 包分发。

## 三、桥接插件

### 1. 故障修复

- 区分 Core 模式生命周期与桥接比赛运行时的启用条件，避免仅凭旧 `caoren` 标识自动开启第二套控制。
- 对齐网页请求、插件确认和比赛事件的身份、修订号及恢复边界。

### 2. 新增/修改内容

- 整合单图 MR12 / MR3 自有比赛运行时，以及准备、暂停、回合备份恢复、阵容与练习管理能力。
- 自有比赛运行时默认关闭，显式启用后才接管支持的正式比赛流程；保留 MatchZy 兼容与回滚路径。存在双控制风险时拒绝开赛。
- 恢复配置或练习清理失败时保持控制权锁，允许管理员显式重试，防止后续模式被迟到的清理覆盖。

## 四、小游戏插件

### 1. 故障修复

- 跨时代 PvP 加强配置和 OCM API 检查，完善日志失败处理、后续采样窗口与生命周期隔离。
- 修正 MC 构建与说明中固定的本机路径，灵空战锋构建工具按 JAVA_HOME 或 PATH 查找 JDK。

### 2. 新增/修改内容

- CS2MiniGames 沿用俄罗斯方块玩法，没有新增小游戏。
- MC 新增灵空战锋 v0.1：独立 4v4 插件、五职业、基地与哨站、兵线、快乐恶魂载具、玩家状态恢复和管理员少人数测试模式。
- 灵空战锋原创原生 26.3 地图模板作为独立附件提供，下载信息及 SHA-256 记录于 MC 包的 `spirit-sky/map-template.json`。
- 坐垫战争 A 由插件负责棋盘生成、模板恢复、缩圈、预警和校验；被替代的旧地图数据包及配套工具退出源码收录和发行包。世界规则、Esc 菜单和独立能力探针继续保留。
- 第三方本地游玩地图及其源码、专用下载工具退出仓库与发行包，通用地图切换功能保留。

## 五、安装与兼容说明

- 提供 CS 服务器、共用网站、MC 三个主包，另附 `CaorenSpiritSky-MapTemplate-v0.1.zip` 原创地图模板。各包附部署指南、许可和逐文件 SHA-256 清单。
- Core、Contracts、娱乐、菜单、异能、随机乱斗和桥接插件应使用配套版本。更新前备份现有配置、数据库、世界和玩家数据。
- 异能 BP、桥接自有比赛运行时、随机乱斗全卡联动及真实客户端完整比赛仍需游戏内验收。此次发布不等于已在现有服务器启用或部署新功能，不卸载 MatchZy。
- 自有比赛运行时需要本地配置与网页本局两个开关同时开启。测试前须在独立实例停用 MatchZy 并完整重启；即使其自动开赛选项为 0，只要程序集仍加载，也会拒绝接管。配套 Core / Ability 共享契约为 v2，旧桥接缺少协议能力时网页不会下发新命令。
- MC 插件使用 Java 25 / 兼容 Paper API 26.3 的服务端。灵空战锋地图仍为粗模，真实八人对局、载具体验、长期性能和平衡待验收；坐垫战争 A/B 也保留各自候验边界。
- 跨时代 PvP 默认关闭，仍待真实客户端和原版对照。本包复用与随包源码 24 项构建输入完全一致的已验证候选；本次构建环境未能复跑完整 Gradle 流程，不将历史 76 项 Java 测试记为本次重跑。
- CS 菜单与音频继续使用既有工坊资源；音频清单沿用匹配的已发布版本。随机乱斗原生辅助库沿用已核验 Linux x64 产物，CS2 引擎镜像变化后必须重新验证。
- 旧坐垫战争地图包不应随新安装添加。已有实例升级时先备份并停服，仅移出已退役的数据包，保留世界存档和插件模板；规则与菜单辅助包按新版安装说明准备。
- 当前 MC 通用切图工具仍会重启服务端，免重启切图方案尚未接入。Windows 服务端路线及 Ubuntu 全新安装流程的实测边界见部署指南。
