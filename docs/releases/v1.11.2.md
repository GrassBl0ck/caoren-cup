# 草人杯 v1.11.2

本次为网页视觉翻新与游戏插件累积更新，包含 v1.11.1 之后的个人统计、换肤入口、单挑发装修复、Friends Vine 与规则文案更新。

## 一、网页端

### 1. 故障修复

- 修复玩家账号已登录但未加入比赛时，换肤入口随大厅容器隐藏的问题；账号有效时入口保持可见，参赛状态不变。
- 更新赛前指引与完整规则 PDF 的连接方式为 `connect play.caorencup.icu`，并同步 HTTPS 说明。
- 网页端版本标识更新为 v1.11.2。

### 2. 新增/修改内容

- 大厅、管理台与赛前指引全面视觉翻新：赛事主视觉、CS2 地图实拍、纸面工作台、统一状态色与组件样式。
- 新增自托管 IBM Plex Sans 字体与完整深色模式；控制台、表单、表格、对话框、地图 BP 与换肤面板同步换肤。
- 响应式重排 1440 / 1024 / 768 / 390：主操作在首屏可见，窄屏不再横向溢出。
- 保留备案页脚、现有登录流程、换肤入口与更新公告；不改变参赛与权限逻辑。

## 二、游戏插件

### 1. 故障修复

- 修复单挑开局发装与换肤出生刷新相互覆盖，导致非主动切刀或切其他物品的问题：换肤只更新现有装备，不再重建武器、补刀或强制切换；发装、选枪与外观回调绑定回合、队伍、连接及带序号出生实体，过期回调自动失效。
- 修复换图、重生、换队或停止后，延迟外观/手套回调仍操作旧实体的问题。
- 修复换肤刷新后默认持枪被二次回调抢回的问题，默认持枪只执行一次。

### 2. 新增/修改内容

- 新增游戏内个人统计：受到伤害、每回合平均、受到道具伤害、射击、命中、命中率，并支持分页查看。
- 模式进入 Live 阶段后自动统计，阶段结束或模式切换时导出对局 CSV。
- 新增 Friends Vine 循环缩放：`/friends_vine`（简写 `/fv`）按阵营在指定倍率区间平滑循环，`/fv 0` 停止并恢复；换图、卸载或重置时恢复原体型。
- 游戏内菜单接入个人统计入口。

## 五、安装与兼容说明

- 服务器插件合集包含本次更新的游戏插件；已安装 v1.11.0/v1.11.1 的服务器请替换合集中对应的 CaorenDuel、CaorenWeaponPaints、CaorenCupInGameMenu 与 CaorenCupFunCommands 目录，并保留现有配置与运行数据。
- 单挑修复需要 CaorenDuel 与 CaorenWeaponPaints 同批更新；建议按 `docs/duel-mode-test-flow.md` 的实机清单复核各阶段、重生、换队与换图。
- 网页端包包含新页面、样式、字体、规则与 PDF；升级时保留 `runtime/`、账号、会话、比赛与换肤运行数据。
- Windows 客户端本次未变更，继续使用 v1.11.1；首页下载入口仍指向 v1.11.1。
- 规则页与 PDF 的连接命令统一为 `connect play.caorencup.icu`；网站使用 HTTPS。
- 本版本包含 v1.11.1 的登录与 HTTPS 修复；Steam 一键登录仍未启用，登录玩家中心后仍需主动加入比赛。
- 弗一把、ParticleMenu、Diagnostics、接口探针、Wingman、Ultimates 不随本版本发布。
