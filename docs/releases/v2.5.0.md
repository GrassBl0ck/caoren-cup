# 草台杯 v2.5.0

## 一、网页端

### 1. 故障修复

网页服务沿用 v2.4.1。

### 2. 新增/修改内容

现有 Windows 客户端可继续使用。

## 二、游戏插件

### 1. 故障修复

玩家菜单和管理员菜单改为居中小窗，缩小打开菜单时遮住地图的区域。

### 2. 新增/修改内容

随机乱斗战斗 HUD 显示 BUFF 图标、等级及主动技能状态。按住查看键可阅读说明，超过六个被动时可展开列表。异能模式显示职业、充能与技能状态，并按职业提供专属情报。

玩家可在 `/cm` 的个人设置中调整 HUD 三栏的位置并保存。玩家菜单提供查看键的绑定指引。管理员菜单仍使用 `/ca` 打开。

## 三、桥接插件

### 1. 故障修复

桥接插件沿用 v2.4.1。

### 2. 新增/修改内容

本版沿用现有比赛回报接口。

## 四、小游戏插件

### 1. 故障修复

小游戏插件沿用 v2.4.1。

### 2. 新增/修改内容

MC 包沿用上一版游戏内容。

## 五、安装与兼容说明

游戏服需同时更新 Core、InGameMenu、Ability 及共享的 CaorenCupContracts，并挂载菜单与音频工坊项目 `3810054981` 的新版资源。客户端会在进服时取得工坊资源。安装前备份插件与配置，保留已有数据。
本版已在 Linux 的 CS2 1.42.0.1 上配合 CounterStrikeSharp 1.0.381 和 MultiAddonManager 1.7.5 验证开图与换图。
