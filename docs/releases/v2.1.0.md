# Caoren Cup 2.1.0：共用账号设置与 MC 开发约定

本版将 2.0.0 发行后的共用账号设置修正纳入网页包，并公开 MC 开发说明和新增系统/玩法接入模板。CS 与 MC 的游戏规则没有变化。

## 一、网页端

### 1. 故障修复

- 将修改登录账号、修改密码的入口统一到共用账户页，CS 大厅提供跳转入口。
- 账号设置不再依附 CS 玩家中心，切换 CS / MC 板块后仍使用同一个草人杯账户。

### 2. 新增/修改内容

- 网页发行版本更新为 2.1.0，保留邮箱注册、邮箱绑定和密码找回流程。
- 本版不再迁移账号数据；保留现有账号、会话、比赛及个人偏好。

## 二、游戏插件

### 1. 故障修复

CS 游戏插件与 MC 玩法本次没有代码修复，游戏二进制沿用 2.0.0 的组件版本。

### 2. 新增/修改内容

- MC 增加公开的开发说明：正式源码统一在主仓库 `mc/`，草人杯外层一次只启用一套玩法/地图，不预留多开。
- 第三方小游戏合集内部保留上游选择和运行方式；自研优先插件、其次数据包，每个玩法单独决定。
- 新增系统/玩法接入模板，记录模块归属、规则、权限、资源、异常处理与验收要求。工程建议仍为审阅稿，不代表旧插件已拆分或玩法已重写。
- MC 打包排除本地协作入口文件，公开开发说明与模板使用仓库内链接。

## 三、桥接插件

### 1. 故障修复

本次无新增修复。

### 2. 新增/修改内容

沿用 2.0.0 桥接组件与一次性游戏身份绑定流程，无需因本次文档调整单独替换桥接插件。

## 四、小游戏插件

### 1. 故障修复

本次未修改 CS 或 MC 小游戏规则。

### 2. 新增/修改内容

MC 包补充开发说明和接入模板；坐垫战争保持试玩待验收状态，跨时代 PvP 保持实验与观察原型状态，实验内容默认不启用。

## 五、安装与兼容说明

- 继续提供三个主包：CS 服务器插件合集、共用网页端、MC 服务器内容包。MC 包内按玩法分目录，不能装入 CS 插件目录。
- CS 服务器包保留 2.0.0 已发布程序与资源，仅更新发行版本清单及源码链接；没有 CS 新功能，不要求重复覆盖安装。
- 网页包纳入共用账号设置修正；已有 2.0 环境保留数据库、运行配置与数据，示例配置不可直接覆盖现有配置。
- MC 包补充开发文档，游戏插件、数据包和固定资源版本不变；大地图与音频仍按固定版本及 SHA-256 另行下载。
- Minecraft 仍仅允许通过正版验证的 Java 玩家进入；本版未增加强制绑定网站账户的入服要求。
- 自研 MC 使用 MIT；OldCombatMechanics 保留 MPL-2.0，小游戏合集保留 CC BY-NC-SA 4.0 及作者附加条款，OCM 仅提供参考源码和构建入口。
- 本版不更新桌面壳、服务端框架或工坊资源。整体发行版本与各插件、地图和资源版本分别管理。
