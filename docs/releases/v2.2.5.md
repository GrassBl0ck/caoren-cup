# Caoren Cup v2.2.5

## 一、网页端

### 1. 故障修复

- 修正赛前指引、完整规则和资料页里过时的玩家登录与身份绑定说明。

### 2. 新增/修改内容

- 玩家用邮箱和密码登录，在 CS2 输入 `/ccbind` 后，将一次性绑定码填入网站个人资料的“CS 游戏身份”。

## 二、游戏插件

### 1. 故障修复

- 普通 `/gm` 正式比赛为每场使用单独的 CS2 回合备份。管理员执行 `/ccrestore 1` 时查找本场第一回合的备份。缺少备份时会提示原因。

### 2. 新增/修改内容

- 游戏内帮助改用 `/ccbind`。

## 三、桥接插件

### 1. 故障修复

- 普通 `/gm` 的 GOTV Demo 由第一个正式回合触发录制。网站暂时断开时，游戏服务器也能发起录制。

### 2. 新增/修改内容

- `/ccbind` 取代 `/cclogin`，专用于获取一次性 CS 游戏身份绑定码。

## 四、小游戏插件

### 1. 故障修复

无改动。

### 2. 新增/修改内容

CS2MiniGames 与 MC 延用 v2.2.4 的游戏内容。

## 五、安装与兼容说明

- 配套更新网页端、CaorenCup Core 和网页桥接插件。Windows 桌面客户端可继续使用 [v2.2.4](https://github.com/GrassBl0ck/caoren-cup/releases/tag/v2.2.4) 的版本。
- 在加载地图前启用 GOTV（`+tv_enable 1`），并在 CS2 服务端启动参数中加入 `-allow_round_backup_files`。录制文件保存在 `csgo/demos/caorencup/`。回合恢复载入 CS2 原生备份。
- 自建实例升级时保留现有账号和身份绑定。完成首次实机对局后，核对 Demo 可以播放且备份可恢复。
