# 草台杯 v2.4.0

## 一、网页端

### 1. 故障修复

- 浏览器中的旧大厅、资料和管理入口会转到下载页。桌面客户端继续使用登录页和账户服务。
- 赛前指引与账户资料使用新版入口，玩家可在客户端内查看常用规则。

### 2. 新增/修改内容

- 草人杯更名为草台杯。官网首页提供 Windows 安装包、下载大小和正式房间的模式说明。
- 网页服务随包提供客户端所需的登录、Steam 绑定、玩家席位、管理员身份及房间接口。玩家可从自己的比赛记录中查找录像。

## 二、游戏插件

### 1. 故障修复

CS2 服务器插件沿用 v2.3.0。

### 2. 新增/修改内容

客户端正式房间开放**竞技、异能**。RUSH、单挑、随机乱斗、卧底和非对称竞技尚未开放正式房间。管理员可以维护卧底任务模板。

## 三、桥接插件

### 1. 故障修复

桥接插件沿用 v2.3.0。

### 2. 新增/修改内容

使用 v2.3.0 桥接插件的服务器可以直接配合新版网页服务。

## 四、小游戏插件

### 1. 故障修复

CS2 小游戏与 MC 内容沿用 v2.3.0。

### 2. 新增/修改内容

MC 完整包保留各玩法的安装说明、源码、许可和固定资源下载入口。

## 五、安装与兼容说明

- **玩家**下载 Windows x64 MSI。安装向导支持自选目录，随包附带完整本地图库（229.8 MiB）。已有 2.4.0 客户端的玩家可继续使用。安装包未经代码签名，Windows 可能显示“未知发布者”。
- **从 v2.3.0 升级的服主**更新网页包及其依赖，保留现有配置、账号、比赛数据和游戏插件。将同页的 MSI 放在网页目录 `public/downloads/caotai-cup-setup.msi`，或通过 `CAOTAI_INSTALLER_PATH` 指定其位置，再启动网页服务。Steam 绑定和管理员配置见网页包的 `ACCOUNT-SETUP.md`。
- **首次搭建**可按需下载网页、CS2、MC 三个完整包。各包根目录有安装说明，附件 `SHA256SUMS.txt` 可校验三个 ZIP 和 MSI。

## 六、Windows 客户端

- 登录后停留在首页。首次参赛可打开赛前指引，在进入房间前核对 Steam 账号。账户菜单提供昵称、头像和换肤入口。
- 管理员可单独主持，也可以玩家身份参赛并同时打开独立管理窗口。六个管理模块和卧底任务模板均可从管理窗口进入。
- 换肤时离开编辑页可以保存、放弃或继续编辑。窗口大小会适应桌面缩放。
