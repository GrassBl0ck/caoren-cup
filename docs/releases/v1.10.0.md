# 草人杯 v1.10.0

本版本带来游戏内菜单、RUSH 模式及音频控制，并将服务器插件按职责拆分。服务器安装包统一为插件合集，网页端独立打包。

## 一、网页端

### 1. 故障修复

- 修正卧底任务卡片的角标遮挡和弹出记录显示，提升较长内容的可读性。
- 同步新的换肤数据路径及当前有效指令说明。
### 2. 新增/修改内容

- 任务卡片显示 N 的可选范围、当前状态和最近操作记录。
- 蓝色提示边框表示仍有未查看提示；查看后移除边框并显示提示内容。
- 本版本继续使用现有账号登录；HTTPS／Steam 登录升级延后至 1.11。

## 二、游戏插件

### 1. 故障修复

- 修复 RUSH 同地图开始下一场时可能因上一场局数上限而提前结束的问题。
- 修正菜单权限、按钮显示、数值调节与个人设置保存，并调整菜单音效。
- 调整伤害查询、旁观席聊天转发及消息格式，保留管理员和普通玩家的使用边界。
### 2. 新增/修改内容

- 提供管理员菜单 /ca、玩家设置 /cm、投票入口 /cv，以及玩家正常对局 MatchZy 指令菜单。
- 支持个人音量、透明度及保存；音频支持暂停、原进度恢复、停止、循环、同通道替换和迟入接入，不修改全局游戏音量。
- RUSH 使用独立插件，管理员 /rush start 可切换官方模式；决胜局资源补丁提供中立塔和击杀后 14 秒抢塔规则。
- 独立竞技模式入口 /competitive 执行玩法重置、退出练习和默认竞技配置；练习仍使用 MatchZy /prac。
- 将 Core、FunCommands、菜单、游戏模式和 QOL 分开组织；Core 提供公共能力，28 项娱乐 Feature 保留在 FunCommands。
- 换肤插件迁入 QOL 分类，保留原 DLL 名称、数据和独立许可证。

## 三、桥接插件

### 1. 故障修复

- 调整单挑期间与网页比赛的隔离及插件间调用，避免旧比赛命令影响单挑过程。
### 2. 新增/修改内容

- 单挑拆为 CaorenDuel，桥接保留网页同步和遥测隔离职责。
- 桥接纳入服务器合集的 CaorenCupWebBridge 分类，保留原 DLL 名称。

## 四、小游戏插件

### 1. 故障修复

- 本版本没有新增小游戏玩法修复。
### 2. 新增/修改内容

- CS2MiniGames 按新的分类目录随服务器合集交付，保留配置、数据库及排行榜。
- CS2Snake 作为外部组件列出，未随本次公开包重新分发。

## 五、安装与兼容说明

- 下载两个主包：CaorenCupServer 服务器插件合集与 CaorenCupWeb 网页端。目录结构、依赖和文件 SHA-256 见包内清单。
- 服务器合集含 13 个主插件及一份共享契约。MetaMod、CounterStrikeSharp、MatchZy、MAM 为独立前置组件。
- 升级前保留配置、身份、个人偏好和数据库，按安装说明处理旧版根目录 DLL；不要直接删除整套插件目录。
- 菜单与音频使用[工坊项目 3810054981](https://steamcommunity.com/sharedfiles/filedetails/?id=3810054981)，音频清单必须与资源版本匹配。
- RUSH 附补丁配方与生成工具，需从目标 CS2 原版脚本校验并生成资源；原版脚本和生成 VPK 不在公开 ZIP 中。
- 暂停的弗一把、ParticleMenu、私有 Diagnostics、开发探针、Wingman 和 Ultimates 不随本版本交付。
- 换肤和 CS2MiniGames 保留各自 GPL-3.0 许可证及对应源码说明。
- 首次菜单资源自动分发已有实际客户端验收；后续工坊版本更新拉取、播放中换地图清音及票数间距专项视觉仍需进一步复核。
