# Caoren Cup v2.3.0

## 一、网页端

### 1. 故障修复

- 网页服务重启后可继续处理同一场正式服的候场和赛后归档。开服长时间未收到游戏服确认时，管理员可以重试。
- 网页恢复连接后补收正式局的战斗记录，按事件身份去重。旧回合的迟到事件不会写回已经回溯的时间线。

### 2. 新增/修改内容

- 竞技和异能模式支持网页正式局。管理员可先完成分队、选图和选边，再开服候场。服务器及地图就绪后，玩家可以从网页打开 CS2 连接入口。
- 网页「准备」与游戏内 `.r` 共用就绪状态。网页可提前准备，玩家到服并加入指定队伍后才计入全员就绪。热身倒计时结束且全员就绪后自动开赛。
- 已配置按场服务的实例会在最终战绩与 Demo 成功归档后关服。参赛玩家可以在赛后页面获取归档结果和录像。

## 二、游戏插件

### 1. 故障修复

- 手动局与网页正式局共用服务器控制权。停止比赛或恢复设置期间，另一条入口不能同时接管。
- 回合恢复等到 CS2 确认目标回合后才报告成功。恢复后按检查点更新手动局战绩，并开启新的 Demo 分段。

### 2. 新增/修改内容

- 管理员快捷菜单提供模式、开始、暂停／继续、重打本回合、回溯、停止和预设公告。默认键位留空。使用 `/crcadmin_bind z` 查看查询、绑定和解绑指引，绑定后按住打开，松开关闭。
- 游戏内管理入口和网页正式局使用 Core 持有的同一份正式比赛状态。

## 三、桥接插件

### 1. 故障修复

- 游戏服在网页短暂离线时继续记录正式局战斗事件，网页写入会话后确认接收。关服会等待最终记录归档完成。
- 正式服启动后在地图就绪时发出第一条心跳，供网页确认该场实例可以候场。

### 2. 新增/修改内容

- 正式局默认启用 `/lobbyreminder 2`。未绑定的玩家留在旁观席，按聊天与中央指引完成 `/ccbind`。管理员可随时使用 `0` 关闭提醒，或用 `1` 切回软提醒。手动局默认使用 `0`。
- 赛前可由管理员补入候场玩家。赛中替补沿用已有参赛席位。

## 四、小游戏插件

### 1. 故障修复

无改动。

### 2. 新增/修改内容

CS2MiniGames 和 MC 内容沿用已有安装。

## 五、安装与兼容说明

- 网页包与 CS 局部更新包配套使用。局部包适用于 v2.2.5，包含 Core、共享 Contracts、网页桥接和游戏内菜单。
- CS2 手动启动时加入 `-allow_round_backup_files`。录制 Demo 时在加载地图前启用 `+tv_enable 1`。服务器可用 `/ccrestore 1` 恢复本场首回合。
- 按住菜单及中央绑定提示依赖配套工坊资源，沿用原工坊项目 [3810054981](https://steamcommunity.com/sharedfiles/filedetails/?id=3810054981)。自动开关服需先配置按场服务实例。
- 卧底玩法沿用 v2.2.5。新版卧底另行安排。
