# 草台杯 Windows 客户端 2.4.0

下载安装附件中的 Windows x64 MSI。自建服请使用 [v2.5.3 起的客户端](https://github.com/GrassBl0ck/caoren-cup/releases)。安装向导支持自选目录。全本地图库随安装包提供，安装包约 229.8 MiB。

- 登录后停留在首页。右上角账户菜单可以换肤、改昵称和头像。点「进入房间」后再核对 Steam 账号并加入比赛。
- 管理员可单独主持，也可以选择「玩家身份」，同时使用玩家和管理员窗口。卧底任务模板位于管理窗口的「卧底任务」。
- 从换肤中心切换到赛前指引或账户资料时，已保存的搭配可直接离开。有未保存修改时，可选择保存、放弃或继续编辑。
- 高缩放显示器上的窗口会适应可用桌面大小。赛前指引使用与客户端按钮一致的名称，常用规则链接在客户端内打开。

**模式范围**

草台杯官方正式房间目前开放竞技和异能。RUSH、单挑、随机乱斗、卧底和非对称竞技暂未在官方客户端正式房间开放。

本次发布 Windows 客户端。自建服务需要相应的桌面账户和房间接口。Windows 可能将此未签名安装包显示为「未知发布者」。
