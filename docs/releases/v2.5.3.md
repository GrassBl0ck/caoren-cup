# 草台杯 v2.5.3

## 一、网页端

### 1. 故障修复

自建站点未配置游戏地址时，CS 大厅不会再复制其他服务器的命令，MC 入服信息会提示服主配置。公开规则页、完整规则 PDF 和部署示例均改为本站指引。

### 2. 新增/修改内容

并入 v2.5.2 试玩版的大厅与房间样式、主题和页面操作调整。Windows 客户端新增房间键位设置，保留已有的启动及 Steam 账号检查。

## 二、游戏插件

### 1. 故障修复

整合试玩版的比赛、个人、投票和管理员菜单导航调整。

### 2. 新增/修改内容

收录管理员快捷菜单及配套核心和共享契约更新。升级 CS 时一起安装本版配套文件，并按部署指南使用对应菜单工坊资源。

## 三、桥接插件

### 1. 故障修复

`/ccreg` 按本站配置显示注册指引；缺少公开网址时提醒玩家联系服主。

### 2. 新增/修改内容

在既有 `caoren_config.json` 中添加 `PublicWebsiteUrl`，填玩家可访问的 HTTPS 网站。`CommandCenterBaseUrl` 继续供插件访问后台。

## 四、小游戏插件

### 1. 故障修复

MC 包修正了指向固定服务器的部署和试玩说明。

### 2. 新增/修改内容

本次沿用现有小游戏玩法和资源。

## 五、安装与兼容说明

GitHub 自建版包含 Windows x64 MSI、CS、网站、MC 三个完整 ZIP 和 SHA-256 校验清单。从源码搭服请看[服主地址配置](../deployment/11-server-addresses.md)，下载 ZIP 的服主请从包根的 INSTALL.md 进入。安装客户端后，在 EXE 旁放置本站的 server.json；安装目录中的 SERVER-SETUP.md 有完整示例。首次使用本版时可能需要重新登录。

更新现有服务器时保留账号、存档和现有运行配置，补齐本站的公开网址与游戏地址，再核对登录、复制命令和入服。GitHub 旧版下载物可能仍有固定地址。
