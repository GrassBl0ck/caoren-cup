# 草人杯 v1.11.1

本次为网页登录与 Windows 客户端修复更新。

## 一、网页端

### 1. 故障修复

- 修复网络异常时未确认服务端退出，却显示退出成功的问题。
- 修复桌面客户端下载入口失效的问题，并将下载版本统一为 v1.11.1。
- 保留现有备案页脚及相关资源。

### 2. 新增/修改内容

- 移除网站自行保存密码及首次保存询问，只保留可选的账号名保存。
- 使用现有会话保持登录：连续 7 天未使用或登录满 30 天后需重新登录。
- 页面启动时清理当前访问来源下的旧密码保存记录，不清除其他偏好。
- 生产环境设备认证要求 HTTPS；本机开发继续支持 HTTP。
- 提供网页后端监听地址配置，便于在同机 HTTPS 代理后限制直接访问。

## 五、安装与兼容说明

- Windows 客户端升级至 v1.11.1，默认使用 HTTPS 网站；公网 HTTP 地址不会用于发送账号密码或设备凭证。
- 网页包与客户端包分别提供；将客户端 ZIP 保持原文件名放入网页的 `public/downloads/` 目录，即可使用首页下载入口。
- 客户端勾选“记住此设备”后，设备凭据继续由主进程加密保存。普通退出结束当前网页会话；“退出账号并忘记此设备”另行清除本机设备凭据并尝试服务端撤销。
- 使用旧 HTTP、IP 或 www 入口的玩家，切换到统一主域名后可能需要重新登录。
- 没有账号或需要恢复账号时，继续使用现有游戏内注册和恢复流程。
- 登录玩家中心后仍需主动加入比赛。Steam 一键登录尚未启用。
- 已安装 v1.11.0 服务器插件的用户无需为本次更新替换游戏、桥接或小游戏插件；只更新网页端和需要升级的客户端。
- 本次发布以 v1.11.0 为基础，不包含之后单独开发的个人统计与 CSV 导出改动。
- 网页检查、客户端测试和安装包内容核验用于验证对应范围；实际 Windows 交互体验仍以实际使用为准。
