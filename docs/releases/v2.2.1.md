# Caoren Cup 2.2.1：CS 消息与管理公示修复

本版是 2.2.0 的补丁更新，统一 CS 消息前缀、颜色和管理修改公示，修复部分操作只有执行者收到提示、全服通知使用私聊颜色及重复发送的问题。既有玩法规则、账号数据结构与 MC 内容保持不变。

## 一、网页端

### 1. 故障修复

本次没有新增网页业务修复。

### 2. 新增/修改内容

网页包发行版本更新为 2.2.1；保留现有共用账户、CS / MC 门户及会话流程。

## 二、游戏插件

### 1. 故障修复

- 聊天和控制台提示统一使用 `[草人杯]`；单人回执为绿色，队伍或指定小组通知为黄色，全服共同通知为红色。分行或较长消息的每条输出都保留一次前缀。
- 补齐循环体型、头部缩放、二段跳，以及移动、装备、修正器、武器精准等管理修改的公示；关闭、清除和恢复默认与开启、修改遵守同一规则。
- 模式选择、启动、停止、进入正式比赛及相关参数修改提供对应通知；异步请求、下回合生效和部分未成功的情况明确说明，避免提前提示完整成功。
- 异能职业分配、更改和清除公开目标玩家及职业中文名，并说明生效时机。管理公示不显示操作者信息；卧底身份、秘密任务、验证码等仍保持原有私密范围。
- 投票公共结果改为一次全服通知，修复逐人发送导致颜色不符的问题；整理音频、小地图、单挑、换肤、帮助、权限拒绝和错误提示的输出。

### 2. 新增/修改内容

本次不新增玩法或调整数值。个人设置与查询仍只回复本人，自动逐帧缩放、HUD 刷新和正常重生重施不会逐次广播。

MC 玩法、实验模块和资源与 2.2.0 保持一致；原有候验、默认不启用及许可限制继续适用。

## 三、桥接插件

### 1. 故障修复

- 对会自行公示结果的草人杯命令，网页桥接不再重复发送同一修改的请求通知；原生服务器参数等异步动作仍明确标注为请求。
- `/notice` 按原有目标小组发送黄色提醒。`/notice all` 明确表示本场网页名单中的在线玩家，不会扩大发送给未加入名单的人。
- 观察者收到的队聊转发使用小组通知前缀，保留原发言者署名及现有接收范围。

### 2. 新增/修改内容

本次不新增桥接协议或账号迁移。共享 Contracts 与调用插件需要配套更新。

## 四、小游戏插件

### 1. 故障修复

俄罗斯方块的启动、操作说明、错误、排行榜逐行内容和个人最佳成绩提示统一接入消息工具。查询“全服排行榜”仍只回复查询者，不会广播个人查询操作。

### 2. 新增/修改内容

小游戏玩法与计分规则不变。MC 包复用 2.2.0 的已发布内容，仅更新发行版本元数据和对应源码链接；CS2Snake 仍作为外部组件列出。

## 五、安装与兼容说明

- 提供 `CaorenCupServer-服务器插件合集-v2.2.1.zip`、`CaorenCupWeb-网页端-v2.2.1.zip`、`CaorenCupMC-服务器内容-v2.2.1.zip`，各包保留安装说明、依赖和逐文件 SHA-256 清单。
- CS 升级时配套更新共享 Contracts 及相关插件；保留现有配置、玩家数据、数据库和音频资源清单，不直接整包覆盖运行数据。框架、工坊资源及 RUSH 补丁仍按既有安装说明准备。
- 本次不修改或分发 SimpleAdmin、MatchZy；CS2Snake 缺少已核定的对应源码及分发条件，不附其二进制。这些外部插件的提示可能仍与统一规范不同。
- 保留现有性能计时调用，私有 Diagnostics 主体、开发控件及音频能力探针不进入正式包。
- 头部缩放原有 Linux 二进制适配与超过 3x 的边缘命中限制保持不变。游戏更新改变服务端二进制后，仍需重新核对原生适配。
- 本次相关本地测试 757 项通过，受影响项目 Release 构建通过，已完成插件加载与无真人命令检查；多人视角的颜色、收件人隔离和完整游玩体验仍待验收。
- MC 的 Java / Paper 要求、实验模块默认状态及第三方许可沿用 2.2.0。各组件保留自身许可证，自研 MIT 不覆盖 GPL、MPL 或其他第三方条款。
