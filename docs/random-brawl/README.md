# 随机乱斗

通过 `/gamemode random` 选择模式，`/gamemode start` 启动。比赛打满24回合，半场换边，12比12结束，无加时。网页与游戏内命令共用模式状态。

通过 `/randombuffs` 或 `/cm` 查看候选、购买与升级。卡池含46项强化，按比赛回合推进品质权重。每回合4券，表现奖励合计最多4券，1000金钱可兑换1券。每回合购买、重抽与兑换各限一次。可免费锁定一张候选，购买其他卡后继续保留。

主动技能可在菜单中发动，或使用 `/rbskill <卡牌名称、编号或内部键>`。玩家须在正式交战阶段存活，服务端统一校验次数与冷却。

root管理员可通过 `/ca` 的随机乱斗玩家状态页选择目标、卡牌、等级与操作。命令 `/rbdebug list` 查询目标，`/rbdebug give <玩家> <卡牌> [等级]` 给予，`set`设级，`remove`移除，`clear <玩家>`清空个人卡，`reset <玩家> [卡牌]`重置次数与待执行任务。团队操作通过卡牌范围或显式team参数影响全队。机器人使用独立会话身份。

共享契约、Random、FunCommands与菜单须配套安装。Linux x64原生辅助库位于Random插件的native子目录，用于逐颗烟雾覆盖和移动散布查询。引擎镜像升级后需要重新验证。构建说明见[原生组件](../../cs/game-plugin/Native/CaorenCupEngine/README.md)。菜单资源由工坊3810054981分发。
