# InGameMenu 第二轮反馈与验收

## 本次变更

- 管理员快捷首页、玩家指令首页隐藏返回箭头；有上级时左上箭头返回，右上 × 始终退出自己的菜单。品牌文字移至左下。
- 移除菜单对原生 mainmenu-content__container 的依赖，使用独立全屏灰色背景。透明度仍为 0% 不透明、100% 透明；1% 对应背景 alpha 0.99。刷新时只撤销默认类、上次类并应用当前类，避免 101 次样式更新。截图异常的根因尚未通过实机确认，本次修正效果待复测。
- 投票选项整行作为按钮；移除右侧“投给 A/B”。可投票行悬停泛白，已投票、管理员和无资格玩家保留只读选项；服务器继续检查投票资格和重复投票。
- 左侧通知显示 A/B/C/D 的具体文本，保留结果提示。
- 玩家列表和详情分页隐藏无效上一页/下一页；管理员分页已有同样处理。
- 新增 `/ca`、`/cm`、`/cv`，复用原命令处理器和权限规则；旧命令保留。
- 全部业务按钮配置短悬浮说明，提示层不参与父布局且不接收鼠标点击。没有新增 Label.html。
- 探针新增 `start 12`、`start 10`；保留 original/18/16。数字代表负 LUFS 响度目标，不代表音量百分比。

- 新音频为双声道 48kHz，均 30 秒：−12 版实测 −11.92 LUFS / −9.93 dBTP；−10 版实测 −9.94 LUFS / −7.95 dBTP。原素材未覆盖，正式默认值未改变。

- 音频方法沿用 FFmpeg 两遍 loudnorm 并复测编码结果，参考 https://ffmpeg.org/ffmpeg-filters.html#loudnorm 。这里调整草人杯素材，不改玩家全局游戏音量。
- 本轮不处理暂停的组件；没有提交、推送、工坊发布。

经用户确认，本轮已备份并更新服务器菜单、PlaySound 两个插件和匹配的服务器/本机 VPK，服务器已正常重启。5 个部署文件哈希、文件属主、19 个插件加载、三个简化命令注册及新音频事件资源检查通过；个人设置和原音频清单保留。本机安装通过既有一键脚本执行，VPK 哈希与服务器一致，gameinfo 未改变。先前检查脚本对插件名称和 find 输出格式的预期不符，修正检查后通过，没有为此重复重启。

## 游戏内验收（须先部署匹配的服务器插件和客户端资源）

1. 完全退出 CS2，安装本轮客户端包，然后重开并连接测试服务器。旧包不要与新服务器混用。
2. 普通玩家输入 `/cm`，管理员输入 `/ca`。普通玩家 `/ca` 仍应被拒绝；`/cv`、`/cv A` 与旧命令等效。
3. 根页面无箭头；详情/设置页面左上箭头返回上一级；从玩家菜单进投票后返回指令页；直接 `/cv` 打开的投票没有上级箭头。每页右上 × 退出，恢复视角控制。
4. 设置透明度 0%、1%、50%、100%，前两者应完全/近乎完全遮住地图；文字保持清楚。分别测试两个入口并重开菜单，确认保存和共享。
5. 第一页无上一页，末页无下一页，单页详情无翻页按钮。悬停导航、数值、帮助、投票和退出按钮，确认短提示不遮住目标、不挤动布局、可以正常点击。
6. 管理员创建带真实文本的二/四选项投票；普通玩家检查左侧通知和菜单选项一致。在行左侧、中央、右侧都试点击，确认泛白并且仅提交一次。管理员/已投玩家不得再次投票；结束后左侧结果仍出现。
7. 固定 CS2 总音量、设备音量，草人杯音量 100%。每段先 `/caudio_probe stop`，再分别 `start 16`、`start 12`、`start 10`，记录清晰程度、爆音、是否盖住游戏声音。此探针只有 root 自己能听到，普通玩家不授予 root。
8. 响度确定后继续原有暂停/恢复、停止和进度测试。暂停时记住阶段，恢复应从原进度继续；重新从头播放不能算通过。循环、同通道替换和后来玩家进度接入仍未验收。
