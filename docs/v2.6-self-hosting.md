## 随包服主指引

- [ ] 源码 README、Windows 安装版及便携版、CS 包、网站包、MC 包各有本地可读的配置入口。复用 `docs/deployment/` 和现有打包清单，让只下载其中一项的人也能找到对应的步骤。
- [ ] 按“改哪个文件或启动项 → 填什么 → 重启哪个组件 → 怎么确认”写清。客户端已有 `CAOREN_COMMAND_CENTER_URL`；网站已有 `GAME_SERVER_CONNECT_URL`（兼容 `GAME_SERVER_ADDRESS`）、`MC_SERVER_ADDRESS`、`CAOTAI_INSTALLER_PATH`；CS 桥接已有 `caoren_config.json` 的 `CommandCenterBaseUrl`。玩家可见的注册站点按 v2.6 最终实现给出准确配置方法。示例区分公网 HTTPS、本机回环地址、CS 的 Steam 连接地址、MC 的主机与端口，以及 MSI 的本地文件路径。
- [ ] 补上首次搭服、仅装 CS 或仅装 MC、部署后换域名、从旧版本升级的验证步骤。独服玩家从服主处取得本站地址或已配好的分发件。官方自用环境所需的生产地址在部署时显式配置。
- [ ] 在 v2.6 的 Release 页和安装说明中标明自建用户应选哪个新包；现存旧标签、附件和用户已经安装的客户端仍可能保留旧地址。历史附件的处置单独确认。

## 发版验收

- [ ] 干净机器、空配置启动 GitHub 下载版，核对实际网络请求、登录页、聊天回复、下载链接、网页显示、复制结果和 PDF。即使地址错误或服务不可用，也不能把用户带回现服。
- [ ] 用服主自己的测试站点、CS 地址和 MC 地址贯通注册、登录、大厅、Steam 进服、控制台复制、MC 地址复制和客户端下载。测试时阻断官服域名及 IP，并检查请求记录，确保独立部署可用。
- [ ] 对准备上传的源码快照、ZIP（含嵌套包）、DLL、MSI/EXE 内的 Electron 应用、网页、PDF 正文与链接及各包配置说明复扫。核对 GitHub 实际附件清单和校验值；不能沿用已知带默认官网的旧 MSI。发行说明也用自建视角走读一遍。
