# 草人杯完整部署指南

本指南面向第一次开服的读者。操作电脑使用 Windows，服务器可以是自己的 Windows 电脑，也可以是远程 Linux 或 Windows 服务器。Ubuntu 24.04 x86_64 为 Linux 命令主线。

文档核对日期为 2026-11-09，代码基线为本地主线 v2.2.1。安装时选用同一版本的发行包，另行记录 CS2、框架、Paper 和资源版本。发行包中的本指南随该包固定，在线主线可能继续更新。

## 选择起点

| 你的目标 | 阅读顺序 |
|---|---|
| 第一次接触服务器 | 开始之前 → 准备环境 → 选择网站、CS、MC 章节 |
| 在自己的电脑开 CS | 开始之前 → 准备环境的 Windows 部分 → CS → 联网 |
| 在自己的电脑开 MC | 开始之前 → 准备环境的 Java 部分 → MC → 联网 |
| 使用网站管理 CS 比赛 | 网站 → CS → 联通 → 联网的 HTTPS 部分 |
| 只运行 MC 玩法 | MC → 联网，网站按需要另装 |
| 已经有服务器，准备升级 | 维护与排错 → 对应组件安装章节 |
| 想编译或修改代码 | 先完成发行包安装，再读源码构建 |

网站账户用于网站登录。MC 游戏入服使用 Minecraft Java 正版验证，当前没有额外强制绑定网站账户的门槛。

## 怎么执行命令

每一段命令前会说明在哪台电脑、哪个终端和哪个目录执行。命令中的示例域名 `cup.example.com`、服务器地址 `SERVER_IP`、账号 `operator` 和标注为 `REPLACE_...` 的值需要换成自己的值。

Windows 章节使用 PowerShell 7。命令块中的 `$env:` 是设置进程环境变量，Linux 的 `export` 具有相似用途。它们只影响当前终端和从该终端启动的进程，新开终端后需要重新设置。

运行成功后再进入下一步。先确认本机连接，再确认局域网，最后让外部朋友测试公网。运行目录、解压目录、游戏目录分别核对，避免把 `addons/` 安装成两层。

## 验证状态

Windows 服务端路线统一为 **未验证**。已知平台限制在各章节单列。Linux 历史环境有部分运行证据，Ubuntu 24.04 从空机器开始的整条路线仍为 **待实测**。编写和打包检查的结果见[验证状态](10-reference.md)。
