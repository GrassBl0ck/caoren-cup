# 归档网页单挑并保留游戏内 `/duel` 设计

## 目标

网页端不再提供或管理单挑模式；网页单挑专属代码、测试和文档迁移到 `archive/web-command-center-duel/2026-08-28/`。生产代码只保留游戏内 `/duel` 流程及其运行所需的通用单挑规则。

## 处理边界

- 网页前端删除单挑开关、地图/回合/道具配置、网页单挑控制面板、网页单挑等待和网页单挑状态展示。
- 网页后端删除 `matchMode: 'duel'` 的网页入口、网页阶段跳转、网页单挑配置下发、网页单挑状态与网页遥测分支。
- 桥接插件保留游戏内 `GameManaged` 单挑、武器与 CVar 规则、掉线暂停、状态查询和 `/duel` 相关指令；将仅服务 `WebManaged` 的代码移入 archive。
- `/duel stop` 直接执行终止流程；删除 `/duel stop confirm` 的解析、提示、状态分支和测试。
- 普通竞技、卧底、锁队和最近新增的不平衡竞技目标人数功能不改变。

## 归档策略

- 独立文件使用 `Move-Item`/等价可恢复移动，保留相对路径和原文件内容。
- 共享文件不整体移动；仅删除网页单挑专属片段，并保留游戏内 `/duel` 所需依赖。
- 归档目录不得进入部署包，不参与生产构建。
