# 普通不平衡竞技目标人数设计

## 目标

让普通网页比赛支持明确的目标人数配置，例如 3v5，并在赛前分队、地图 BP、赛前准备和锁队同步等关键节点阻止人数或绑定状态不完整的比赛开局。单挑模式保持现有行为，不纳入本次修改。

## 用户流程

1. 大厅管理员在本局模式设置中选择平衡竞技或不平衡竞技。
2. 选择不平衡竞技后填写 A 队和 B 队目标人数；默认提供 3v5 示例，但允许其他正整数配置。
3. 保存后，分队页面持续显示目标人数、当前人数、未分队人数和未绑定 SteamID 人数。
4. 管理员在蛇形选人阶段手动分队。系统不强制均分，但显示距离目标的差额。
5. 进入地图 BP、赛前准备和标准竞技 `.start` 前，统一检查目标人数、所有参赛者已分队以及 SteamID 已绑定。
6. 有人退出或新加入导致状态失效时，页面显示具体原因；管理员修正分队或绑定后才能继续。
7. 同步网页强制分队时，如果存在未绑定玩家，接口直接拒绝下发，并列出玩家姓名。

## 状态与接口

- 在 `matchOptions` 增加不平衡竞技开关和 A/B 目标人数字段；平衡竞技保持兼容默认值。
- 目标人数只在大厅阶段可编辑，进入队长选择后锁定。
- 增加共享校验函数，供阶段推进、赛前开始和 team-lock sync 使用，避免各处规则不一致。
- 单挑模式不读取这些目标人数，不改变其分队、等待和开赛逻辑。

## 页面表现

- 模式设置中提供“平衡竞技 / 不平衡竞技”选择；不平衡竞技显示 A 队人数、B 队人数输入。
- 分队面板显示“目标 A 3 人 / B 5 人”和实时计数。
- 不满足条件时显示简单中文原因，例如“B 队还差 1 人”“有 1 名玩家未绑定 SteamID”。
- 平衡竞技继续显示现有流程，不增加新的阻断。

## 校验规则

- A、B 目标人数必须是正整数。
- 总目标人数必须等于当前参赛玩家数；不一致时不能推进到地图 BP或正式开始。
- A、B 实际人数必须分别等于目标人数。
- 不允许存在未分队参赛者。
- team-lock sync 必须要求所有目标参赛者均已绑定 SteamID。
- 管理员和旁观者不计入目标人数。

## 兼容与风险

- 旧会话没有目标字段时按平衡竞技兼容处理，避免恢复旧大厅失败。
- 不改卧底身份数量规则；不平衡竞技建议关闭卧底模式，但本次不额外改变身份系统。
- 不修改服务器端 MatchZy 开赛方式，只在网页流程和同步接口增加门禁。

## 验证

- 单元测试覆盖默认兼容、3v5 满足、4v4 不满足、未分队、未绑定和玩家进出后的重新校验。
- 执行网页端 `npm run check`。
- 检查 git diff、残留引用和忽略文件，确认未包含备份、构建产物或密钥。
