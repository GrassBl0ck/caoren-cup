坐垫战争 A：每一回合都要想清楚

红蓝两队在独立棋盘地图上轮流行动。移动、攻击与掩体组成一场回合对决，随着战场缩小，争夺中央目标和判断时机越来越重要。

  1. 进入坐垫战争地图后，在候场区使用红、蓝队物品选择队伍。
  2. 支持 1v1 至 8v8，由管理员设置人数并开始对局。
  3. 轮到己方行动时按游戏提示操作，关注计分板、行动点与回合倒计时。
  4. 这是待真人验收的试玩版本，遇到问题请向管理员反馈。

怎么加入

准备好，进入服务器

需要 Minecraft Java 版正版账号。连接服务器时由游戏进行正版验证，网站账户不替代游戏账号。

  1. 在启动器中登录正版账号，选择 正在读取版本……。
  2. 进入“多人游戏”，选择“添加服务器”。
  3. 粘贴下面的服务器地址，然后连接。
