# 真人 / 真实服务端测试清单（NOT_RUN）

本轮只做本地构建与不启动游戏服务的自动测试。以下步骤**尚未执行**，需要用户另行授权隔离
服务端/客户端后进行；不得把本清单当作通过记录。

## 前置

1. 隔离测试服使用 Paper 26.3（Java 25），独立世界与独立插件数据目录，不使用生产存档。
2. 安装 `CushionWarsRealtime-0.1.0.jar`，启动参数显式加 `-Dcw.map=cushion-wars-b`。
3. `plugins/CushionWarsRealtime/config.yml` 的 `board.world/center-x/center-z/ground-y`
   指向隔离世界；首次启动允许插件生成默认棋盘（会写方块）。
4. 记录服务端版本、JAR SHA-256、世界名、配置 origination；测试前后备份世界。

## 基础加载与地图守卫

- [ ] 不设置 `cw.map` 启动：插件待命，`/cwb help` 提示未启用；世界无方块变化。
- [ ] 设置 `-Dcw.map=cushion-wars-b`：日志出现启用信息，默认 4v4 棋盘生成。
- [ ] 设置非法 `rules.team-size: 9` 或不存在世界：插件拒绝启用并给出明确错误。
- [ ] 确认未注册 `/cw`、`/maps`；`/cwb` Tab 只显示允许的子命令。

## 1v1 / 4v4 / 8v8

对每种人数：

- [ ] `/cwb size N` 恢复对应模板；目视边长 19/31/47，中央 3×3 金块，掩体 2 格高。
- [ ] 双方各 N 人 `/cwb join red|blue`；聊天按钮选点；抢同一点只有先者成功。
- [ ] 有人未选位时 `/cwb start`：随机补齐，5 秒准备，人数不足拒绝。
- [ ] 准备期间 sneaking/离开座位被阻止；`/cwb spawn`、换队被拒绝。
- [ ] 开始后 5 秒、85 秒各补给 1 坐垫/1 门；库存满不累计。
- [ ] 首次 20 秒缩圈、提前 3 秒预警；最后 86 秒到 5×5；90 秒截止无加时。
- [ ] 4v4 逐项对照旧稿的 13 次缩圈时点（20、25.5、…、86 秒）。

## AP、移动与交互

- [ ] 第 1.4 秒首次消耗普通 AP，约 2.9 秒恢复；中途再消耗不改变恢复时点。
- [ ] 三次临时 AP 可同时存在，各自 3 秒；右键时钟提示剩余次数；满 3 秒同刻失效。
- [ ] 有临时 AP 时先扣临时点；临时点消耗不启动普通恢复。
- [ ] 成功换座后 1 秒内再次换座失败且不扣 AP；同一空座竞争仅一人成功。
- [ ] 无 AP 放垫/射箭失败，不扣库存/箭；掩体上、越界、已占格放置失败。
- [ ] 有人坐垫不可拆；无人己方/敌方坐垫可拆；门开/关/拆各 1 AP；门与坐垫互斥。
- [ ] 主动下座被阻止；只能在己方坐垫上；死亡/断线后不能继续操作。

## 战斗、治疗与同批顺序

- [ ] 半蓄力普通箭 3 HP、满蓄 6 HP；伤害箭额外 +6；最短 3 tick 射击 0.9/6.9。
- [ ] 己方箭穿本人/队友；命中敌方只扣血，不击退/不下座；逐箭独立伤害。
- [ ] 箭命中地形清除；10 秒未命中清除；截止清除未命中箭。
- [ ] 4 HP 玩家同批受 1 点衰减 + 3 点箭伤死亡；治疗不能救回。
- [ ] 同批先伤害后治疗；缩圈/衰减先于治疗。
- [ ] 双方同批全灭平局；一方中央 9/9 但最后一人同批死亡时按歼灭判负。
- [ ] 1799 tick 合法事件计入；1800 tick 新操作/命中不计；截止按中央格数、存活人数比较。
- [ ] 治疗 I 4 HP、喷溅 II 8 HP 且受距离/上限影响；空瓶清理只限本局物品。

## 信息与观战

- [ ] 己方计分板显示每名队员生命、普通 AP、临时 AP、激活机会、坐垫/门库存。
- [ ] 准星指向无遮挡敌人显示其当前/最大生命；移开/遮挡隐藏；不显示敌方 AP/库存。
- [ ] 公共区域显示比赛钟、双方存活人数、中央格数、棋盘大小。
- [ ] 死亡/断线本局淘汰；重连只能观战并跟随己方存活者；不能自由侦察。
- [ ] 所有聊天消息均为 `[草人杯]` 前缀，个人绿/全体红/己方黄，无重复前缀。

## 生命周期、编辑与恢复

- [ ] 正常结束、管理员 stop、准备缺人取消、停服：均回等待，结果/无胜负提示正确。
- [ ] 赛后恢复背包、模式、生命/上限、位置、药水效果、计分板；只清理本插件物品。
- [ ] 连续两局：重新选队/选位，不沿用上局点位；旧箭/治疗不跨局生效。
- [ ] `/cwb edit begin 4`：创造编辑，exit 放弃未保存方块，save 后下一局/重启使用新模板。
- [ ] 保存非法模板（中央非金块、出生点上方有方块、容器）被拒绝，旧文件保留。
- [ ] 重启服务端：模板、配置人数与保存结果保持；损坏 recovery 记录不清空玩家背包。
- [ ] 恢复/传送失败时不开始新局，保留记录与现场。
