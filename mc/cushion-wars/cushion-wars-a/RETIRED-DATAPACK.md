# 旧数据包地图层退役记录

2026-11-12，用户确认以插件继续实现复杂玩法，将已被插件替代的旧地图层退出正式源码、构建和发行包，并在仓库外归档。

旧地图层最初为纯数据包路线编写，后来沿用“插件管玩法、数据包管地图”的拆分。当前 ArenaManager 已承担建图、模板恢复、缩圈、预警和地图校验；继续维护展开的 1～8 队伍尺寸命令及其专用生成器，会形成重复实现。这是本次退役原因，文件体积与 GitHub 语言占比只是这一历史遗留的表现，不构成运行性能结论。

退出范围：src/round-a/、maps/、tools/gen_map.py、layout.py、verify_map.py、build_pack.py，以及依赖旧地图函数的 cw-autoverify、cw-maptest。其源码、几何清单、原工具、原结构快照及逐文件哈希保留在工作区外的 cushion-wars-a-map-datapack-complete-20261112 本地归档。Git 基线为 b704e82bd4f99411b9388e46b10cee32cd172254，历史没有重写。

继续保留：现有玩法插件、cw-entry 世界规则、cw-maps-menu 菜单、独立 P0 能力探针及通用地图管理工具。正式安装使用插件和规则/菜单两个辅助包；旧地图包不再安装。诊断与历史文档中的 /function cushionwars_a:... 已失去当前支持，正式地图操作以 /cw 为准。

source-manifest.json 保持原历史证据；source-layout.json 明确登记退役范围，来源校验和发行源码选择均排除这些项。恢复需重新获得用户确认，并验证与当前插件的地图职责、坐标、模板和版本不会冲突。

本次仅处理本地源码，不连接、不修改生产服务器、地图世界或玩家存档。已有服务器的旧包仍需后续单独安排备份与迁移验收，不能把本次归档视为已完成线上切换。
