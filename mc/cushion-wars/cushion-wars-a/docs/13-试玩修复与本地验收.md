## 玩家与管理员命令

玩家：
- 右键候场道具加入红/蓝队或退出；背包已有私人物品的栏位不覆盖。
- /cw join red、/cw join blue、/cw leave、/cw status。
- 入局前存放非比赛物品，包括装备、副手。不会删除原有物品强行开局。
- 比赛中手持时钟右键确认结束，再右键取消确认。

管理员：
- /cw size 1：直接切换为1v1并恢复模板；1—8对应每队人数。
- /cw build [人数]：需要时重新恢复对应模板，可省略人数使用当前设置。
- /cw start：红蓝各满员后开始介绍和准备。
- /cw stop：中止当前局；赛后调用保留已经判定的结果。
- /cw skip：跳过正在播放的介绍。
- /cw edit begin 4：恢复并进入 4v4 编辑。
- /cw edit save：保存当前人数的棋盘地面与上方两格掩体。
- /cw edit exit：退出并恢复已保存模板，放弃未保存棋盘修改；背景景观由世界存档保存。

编辑时中央 9 格地面保留金块，其上及出生点上方留空；地面须有实心支撑，掩体高两格，比赛施工区保持露天。景观请建在最大 47×47 比赛区之外。模板不保存局内坐垫、门、掉落物或投射物，按人数存于插件数据目录 arenas/n1.yml 至 n8.yml。

默认设置仅下一局生效：
- /cw config show
- /cw config set personal-ap 2
- /cw config set red-shared-ap auto
- /cw config set blue-shared-ap 4
- /cw config set initial-health 40
- /cw config set max-health 40
- /cw config set action-seconds 30

共享值 auto 随每队人数 N 推导；个人 AP 全员统一。AP 为 0—1000，最大生命为 2—1024，0 < 初始生命 ≤ 最大生命，行动为 1—3600 秒。改小最大生命前先相应改小初始生命。当前局始终使用开局快照。

## 下一轮真人验收顺序

1. 非 OP 双人 1v1：介绍可看、可跳过，准备后均正确入座。
2. 正常结束、管理员中止、结束后再 stop：均能下座、安全活动、重新入队再开局，无飞行踢出。
3. 个人/共享 AP 用尽后，放垫、换座、拆垫、门操作均不再生效且不消耗物资；副手不能绕过。
4. 有人坐垫拆不掉，无人坐垫扣 1 AP 且不掉物品；旁观和未入队玩家不能免费拆垫或改图。
5. 完整回合补给、库存上限、空投射物立即切阶段、飞行投射物最多结算 5 秒。
6. 第 6 回合看见危险圈预警，第 7 回合真实收缩；中央铺满必须撑过敌方完整行动与结算。
7. 不断线与断线重连、喝药跨阶段、Tab/BossBar/道具清理、地图模板重开与重启恢复。
8. 2v2：共享 AP 竞争、全队确认/取消、中央反制窗口。
