# Minecraft 跨时代战争：阶段03开发环境

本目录是可复现的开发环境起点。旧版战斗基准为1.8.9，现代目标为26.3。

## 当前组件

- CrossEraProbe：只观察伤害事件，记录时间、tick、攻击者、受击者、伤害和取消状态。
- Paper API固定为26.3 build 223；编译使用Java 25。
- 记录保存到服务器内本插件的数据目录，文件名为events.jsonl。
- 管理员使用 /ceprobe status 检查记录数量与写入错误。

## 验证边界

本探针不实现旧版战斗、规则切换或伤害重算。原版1.8.9和原版26.3对照服保持无插件。
原生命令触发的事件用于验证记录通路，不能代替真实玩家PvP和原版还原验收。

后续小游戏调用自有战斗接口。初期通过OCM适配，正式小游戏开发前完成独立化。
正式部署遵守现有Esc菜单切图约定，并为玩法插件设置加载边界。

## 构建与版本控制

Gradle Wrapper固定版本后可运行gradlew.bat jar，Linux使用./gradlew jar。
构建输出位于build/libs。运行时、世界、缓存、日志和真实服务器配置不进入源码仓库。
公开仓库名称、许可证及首次提交推送尚待确认。
