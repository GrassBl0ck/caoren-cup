## 单玩法与规则

外层一次一个玩法/地图，不引入多房间或常驻副服。默认世界名为空，未配置时不接管世界。玩家加入前快照，退出恢复；运行中不接收新参赛者，允许观战。管理员先取消对局再切图。不修改其他玩法、网站或正版登录链路。

具体胜负、8 人准备、选职、复活掉线、代理驾驶交接、旁观、同 tick 双基地归零和异常中止均按规则汇总实现。没有金币、奖励、战绩或网站绑定；不新建这些系统。`rules.yml` 首次生成已确认默认值，包含库存上限和再生、主要计时、建筑/载具生命、伤害、射程、兵线和飞行倍率；修改需重启。五阶段成长曲线、箭衰减分段等结构规则保留在源码；修改规则须先确认。地图点位由配置指定，不允许局中重载。

## 数据、权限与影响范围

| 对象 | 修改范围 | 保存和恢复 |
|---|---|---|
| 玩家 UUID / 账户 | 以服务器 UUID 识别 | 不增加网站绑定 |
| 背包 / 模式 / 血量 / 饥饿 / 效果 / 位置 / 飞行等 | 仅已加入的玩家 | `player-snapshots/<UUID>.yml`，原状态落盘后才发道具；恢复成功保存玩家后归档快照 |
| 世界方块 | 对局禁止任意挖放，建筑用展示与受击实体 | 不覆盖模板，不修改实体外的地图方块 |
| 实体与区块 | PDC 标记本插件本局；地图范围区块票据 | 结束移除归属实体；停用移除本插件票据 |
| 界面 | 本插件 BossBar、菜单和 ActionBar | 结束清理 BossBar 与菜单，不接管其他计分板 |
| 结算 / 奖励 | 显示胜负 | 没有外部奖励与结算数据库 |

消息由 `Game.tell/team/announce` 和插件控制台回复入口统一加 `[草人杯]`，个人绿、队伍黄、全体红。

## 启停与异常处理

- 世界或点位无效：不开放玩法，保留恢复入口和错误日志。
- 连续两局：结算后返回准备区，手动准备；清理实体、计时、冷却、哨站和代理驾驶状态。
- 死亡、离线、重连：原参赛者保留队伍/角色与计时；完整重启不恢复战斗局，恢复场外状态。
- 快照损坏、世界不可用或恢复传送失败：不删除快照，阻止继续携带临时物品游戏并提示管理员。
- 关闭：停止本插件调度、清理实体与界面、恢复在线玩家；离线玩家快照在下一次上线恢复。
- 所有 Bukkit 世界与实体操作在主线程；快照是低频边界写入，先保证持久化。没有网站请求或后台外部服务。
