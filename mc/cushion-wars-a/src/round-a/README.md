# 数据包源码（src/round-a）

本目录是回合制 A 的正式数据包源码，但**当前只包含不依赖未验证能力的层**：地图层、状态推导层与组织者入口。玩法层（输入门禁、坐垫/门事务、战斗、治疗、观战、信息面板）**尚未实现**，原因是 P0 关卡一次都没有真实客户端证据，按主任务第 8 节与转交说明第 3 条，证据不足时不得推进依赖该能力的正式实现。

## 已实现

| 路径 | 职责 | 依赖 | 状态 |
|---|---|---|---|
| `function/bootstrap/load` | 注册计分板、常量、比赛状态初值 | 无 | 已写，未在 26.3 加载 |
| `function/bootstrap/tick` | 挂点占位，不做任何状态推进 | 无 | 已写，未在 26.3 加载 |
| `function/core/set_round` | 由回合数推导半径、边长、最大生命（纯算术） | 无 | 已写，算术已静态复核 |
| `function/arena/init` | 全量预检后建图，框内非空气则拒绝 | 无 | 已写，未在 26.3 加载 |
| `function/arena/build` | 调用生成的建造函数 | 无 | 已写 |
| `function/arena/reset` | 清空施工框并重建 | 无 | 已写 |
| `function/arena/shrink` | 按回合清除失效圈 | 无（不含缩圈致死判定） | 已写 |
| `function/arena/warn` | 用粒子显示下一失效圈 | 无（不改方块、不改碰撞） | 已写 |
| `function/arena/selfcheck` | 逐格比对地面、掩体、出生坐垫 | 无 | 已写 |
| `function/admin/*` | 组织者帮助与回合设置 | 无 | 已写 |
| `function/arena/gen/*` | 由 `tools/gen_map.py` 生成，禁止手改 | 无 | 已生成，32 项静态校验通过 |
