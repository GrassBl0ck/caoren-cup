## 目录

| 路径 | 内容 |
|---|---|
| `tools/layout.py` | **几何唯一来源**：边长 = 4N+15、出生点阶梯、掩体分组规则（N=4 逐格复现设计稿） |
| `maps/m1/board.json` | 设计稿 M1 的历史源数据，保留作 N=4 回归基准 |
| `maps/sizes/` | 8 个尺寸的清单与字符图（`MAP-n<N>.md`、`board-n<N>.txt`、`SIZES-SUMMARY.json`） |
| `tools/gen_map.py` | 由 layout.py 生成 8 个尺寸的数据包函数（地面、掩体、出生坐垫、自检、缩圈、预警，共 260 个文件） |
| `tools/verify_map.py` | 独立复核几何与生成产物一致性（177 项） |
| `tools/verify_pack.py` | 数据包结构、引用完整性、命名空间隔离、后门检查（16 项） |
| `tools/build_pack.py` | 构建 ZIP、SHA-256 与构建清单 |
| `src/round-a/` | 正式数据包源码（`cushionwars_a`），只含地图层与状态推导层 |
| `prototypes/round-a-p0/` | 数据包侧 P0 隔离探针（`cw_p0`），只做记录，不含玩法 |
| `plugin/` | **Paper 26.3 插件源码**：`probe/` 能力验证（G01/G02/G04/G07）＋ `game/` 一局流程（`/cw`） |
| `deploy/server/` | 服务器运维源码：`mapctl`（地图切换）、`mcctl`（RCON 调试）、`cw-entry/`（地图自举包）、各地图 `map.conf` |
| `checks/` | 校验结果 JSON + Markdown |
| `docs/` | 安装、P0 协议、语法待验证清单、能力风险评估、限制与阻塞、插件验证方案、对局手册、**多地图切换方案** |
| `dist/` | 交付产物：2 个数据包 ZIP + 1 个插件 jar + 校验清单 |
| `handoffs/` | 交付报告 |
| `references/` | 设计稿与原包审计快照，**只读**，不修改 |

## 复现全部静态检查

```
python tools/gen_map.py       # 生成数据包地图函数与地图清单
python tools/verify_map.py    # 29 项几何与产物一致性
python tools/verify_pack.py   # 15 项数据包结构与引用完整性
python tools/build_plugin.py  # javac + jar，输出插件 jar
python tools/verify_plugin.py # 13 项插件打包与声明自洽
python tools/build_pack.py    # 输出 dist/*.zip 与 SHA256SUMS.txt
```

全部为确定性运行：同一输入得到同一字节序列，可用 `dist/` 下的校验清单复核。
