# 拉人测试流程

> 这是原部署版本的测试流程。2026-10-31 新版本尚未部署；更新后的验收项与编辑/配置命令见 [试玩修复与本地验收](13-试玩修复与本地验收.md)。

> 2026-10-27 20:25 整理。当前状态：`cushion-wars` 地图运行中，棋盘是 4v4（31×31），0 人在线。

## 一分钟版本

```
1. 所有人用 Minecraft 26.3 客户端连 123.206.213.166:25565
2. 你先在游戏里敲：/whitelist add <朋友的名字>     ← 白名单只有 5 个号
3. 你敲：/cw build 1                               ← 重建 1v1 棋盘（19×19）
4. 两人各自敲：/cw join red  /  /cw join blue
5. 你敲：/cw start                                  ← 5 秒后开打
```

## 一、三个硬性前置

| 项 | 现状 | 说明 |
|---|---|---|
| 客户端版本 | **必须 26.3** | 你的启动器里之前只装到 26.1.2，先装 26.3 正式版。低版本连不上（协议不兼容） |
| 白名单 | 只有 5 个号：`GrassBl0ck_`、`phxfan`、`qingqiyuan`、`Ginreny`、`chelin_` | `white-list=true` + `enforce-whitelist=true`，**不在名单里的人会被拒绝**。加人：游戏内 `/whitelist add <名字>`（你是 OP），或告诉我名字我来加 |
| 人数上限 | `max-players=10` | 所以最多 5v5。白名单只有 5 个号，实际上现在最多 2v2 |

## 二、玩家进服后看到什么

- 出生点已经被数据包固定在棋盘边（`20000, 200, 19986`），**不是世界原点**，一进去就在棋盘旁边；
- 游戏模式是**生存**，脚下是棋盘地面，四周是空气——**掉下去会摔死**（摔死不掉东西，`keep_inventory=true`，但得重新跑回来）；
- 按 **Esc** 应该能看到「地图传送」按钮（这一项还没人验证过，第一个要看的）。

## 三、组织者开局

全部是你（OP）执行，普通玩家执行会提示"只有管理员可以…"。

```
/cw build 1          # 按 1v1 重建棋盘。会先清空 47×47 再建，约 2—3 秒。
                     # 想打 2v2 就写 /cw build 2，边长 23×23。
/cw status           # 随时看阶段、回合、剩余秒数、存活人数、谁在哪个队
```

然后玩家各自：

```
/cw join red
/cw join blue
```

你：

```
/cw start            # 校验红蓝各恰好 N 人，否则报"人数不足"
```

开局后自动流程：

```
5 秒准备：传送到各自出生坐垫 + 自动上座 + 发装备 + 生命设成 40
   ↓
先手方 30 秒行动（底部行动栏显示 第N回合·队伍·剩余秒·AP·HP）
   ↓
10 秒结算（等箭落地）
   ↓
后手方 30 秒行动 → 10 秒结算
   ↓
第 7 回合起缩圈，第 12 回合起生命衰减 → 一方全灭或中央 9 格被占满则结束
```

中途出问题：`/cw stop` 中止。想重来：`/cw build N` 重建棋盘。

## 四、测试清单（按优先级）

### A. Esc 菜单（1 分钟，先验这个）

1. 按 Esc → 有没有 **「地图传送」** 按钮？
2. 点开 → 排版、中文是否正常显示？
3. 点「查看当前在哪张地图」→ 聊天栏是否输出两张地图并标出当前？
4. （你一个人就能测）点「草人杯小游戏合集」→ 应该 5 秒倒计时后关服，约 20 秒后自动起在小游戏合集。再按 Esc 点「坐垫战争」切回来。

**这一项如果没出现按钮，把现象告诉我**——服务端侧已确认 JSON 被接受、标签注册成功，说明问题在显示层，我需要现场再查。

### B. 一局能不能跑完（10—20 分钟）

5. 两个人都能正常入队、开局、被传送到出生坐垫、自动坐上去吗？
6. 底部行动栏是否只在轮到自己时提示"轮到你行动"？
7. 30 秒到点会自动切到对方吗？结算阶段会出现吗？
8. 一方被打死后是否转旁观、另一方判胜？
9. 打满 7 回合后棋盘有没有缩小？

### C. 能力验证（这是设计稿里最容易做不到的三条）

10. **AP 门禁（G01）**：个人 AP 2 + 队伍共享 AP N，放超了会提示"AP 不足"，**而且背包里的坐垫数量不能少**。
11. **禁止下座（G02）**：坐上坐垫后按 Shift，人应该还坐在上面动不了。
12. **逐箭伤害（G04）**：满蓄力 6 HP、半拉约 3 HP、轻点约 0.9 HP，药箭额外 +6。是定值，不是原版那种随机伤害。
13. **准星血量（G07）**：看向对面阵营的玩家，屏幕下方显示对方名字和血量。

### D. 顺带看一眼

14. `/cw status` 的输出是否与实际相符。

## 五、会踩的坑（先说清楚，别当成 bug）

| 现象 | 原因 | 处理 |
|---|---|---|
| 掉出棋盘直接死 | 棋盘是悬空平台，没有边界墙 | 设计如此。死了重生在棋盘边，`/cw stop` 后 `/cw build N` 重来 |
| 大家能互相砍、能挖方块 | 生存模式，**近战禁伤和防破坏还没实现** | 测试期靠自觉。这也是后面要补的 |
| 只有你能 build/start | 权限 `default: op`，其他人不是 OP | 有意如此 |
| 人数差 1 个也开不了 | `start` 要求红蓝**恰好各 N 人** | `/cw leave` 退出多余的人 |
| 切地图后要手动重连 | 切图 = 重启服务端，客户端不会自动重连 | 点"重新连接"即可 |
| 切地图后小游戏合集里 20 个老地图没数据包 | 不可能 | 切图是整世界切换，它们跟着一起过去，不受影响 |

## 六、出问题我能做什么

- 实时查状态：`/cw status`、计分板、在线玩家、TICK 情况

- 立刻 `systemctl stop caoren-mc` 停服
- 回滚到备份（`/var/backups/caoren-mc-*`）

**建议**：测试时把现象告诉我（尤其"A 步骤没看到按钮"这种），我可以一边查日志一边判断是显示层还是逻辑层的问题。

## 七、测完想换地图

你（OP）在游戏里按 Esc → 「地图传送」，或者命令行：

```bash
ssh root@123.206.213.166
cd /opt/caoren-mc-26.3 && ./mapctl list      # 看当前
./mapctl use minigames                        # 切到小游戏合集
```

注意 `./mapctl use` 和 `/maps goto` 做的是同一件事（改 `maps/active` + 重启），走哪边都行。
