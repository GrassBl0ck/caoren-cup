## 3. 需要你决定的小问题

1. **固定白昼、晴天、关闭自然生物生成**：数据包可以写 `time set`、`weather clear`、`gamerule doDaylightCycle false`、`gamerule doMobSpawning false`，但这些是**整个世界**级别的设置，会连带影响同世界的其它用途。当前包没有写。请决定：由数据包统一设置（简单，但世界被占用），还是写进开服/世界参数（干净，但组织者需手动配置）。
2. **准星血量的显示方式**：sidebar、actionbar、头顶文本三种呈现方式观感差异明显，且“准星指向”只能用射线近似。等 G07 有了实测结论再定更合适。
3. **预警圈的表现**：当前用火焰粒子勾出下一圈的边界（只播撒粒子，不放置方块、不改变碰撞与射线）。若你希望换成别的表现（例如染色玻璃边框），需要在“不遮挡射线”的前提下另选，否则会改变原版射击与视野。

## 4. 已知的实现层风险

- 所有 26.3 语法与实体标识均未经实际加载核实，逐条列在 `docs/03-26.3语法待验证清单.md`。首次在真实 26.3 加载时，极可能需要按报错修正 `pack.mcmeta` 字段、目录单复数或实体 ID。
- `arena/init` 的预检一次执行 2883 条命令，可能造成一次明显的 tick 卡顿（一次性）。若实测 TPS 掉得厉害，可改为分段执行（每 tick 一层的 2883/3）。
- 缩圈清理里的 `kill @e[...]` 依赖实体 ID 正确；ID 若不符，坐垫会残留，但方块清理不受影响。
- 地图自检 `selfcheck` 依赖坐垫实体的 NBT 与位置，若 `summon` 的 `TileX/TileY/TileZ` 语义不符，会报出 8 处不符——这本身就是一个有用的诊断信号。
