# 回合制 A：验收矩阵

日期：2026-10-25。**以下全是待执行情景与预期，不是已通过的测试。** 实施方须逐项填写实际结果。

## 1. 记录方式与证据层级

每个用例记录：ID、版本/工作目录、前置状态、实际输入或命令、期望、实际、证据路径、状态、问题编号。

- S：文件/几何/算术静态检查。
- F：服务器命令或内部状态函数测试；不能单独证明原版输入事件。
- C：真实原版客户端操作；按用例需要安排人数，不能仅用标记实体代替玩家。
- M：正式八人对局的综合场景，红蓝各 4 人，使用正式入口。

状态只填 PASS、FAIL、NOT_RUN、BLOCKED。需要 C/M 的用例，只有 S/F 证据时不能填写 PASS。缺少条件如实写未测。人工场景可以有自动断言，但要保留真实输入/命中证据。

P0 至少覆盖操作、乘坐、门、战斗、治疗、观战和信息隔离中支撑正式实现的全部必要能力。P0 的几个演示视频不等于整表通过。
