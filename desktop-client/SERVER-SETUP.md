# 选择本服网站

1. 向服主索取本服网站的 HTTPS 地址。在安装目录里找到客户端 EXE，在旁边新建 UTF-8 文件 `server.json`。便携版放在下载的 EXE 旁，源码运行时放在 `desktop-client/` 下。
2. 写入下列内容，把示例域名换成本服域名，保存后重新打开客户端。

```json
{"website":"https://cup.example.org"}
```

服主可以把自己填好的文件随便携版发给玩家。安装目录没有写入权限时，可在 Windows 用户环境变量里设置 `CAOREN_COMMAND_CENTER_URL`，值填本服网址，再重开客户端。该变量优先于文件。本机调试可用 `http://127.0.0.1:3000`。

未配置、地址格式无效或使用公网 HTTP 时，客户端显示本地配置说明。更换站点后请用该站点的账号登录。在本站网页和客户端打开同一账号，核对大厅和房间是否一致。
